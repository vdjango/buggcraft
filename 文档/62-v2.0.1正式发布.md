发布所有者仍是 `.github/workflows/package.yml`。本次一次性 Windows runner 干净 checkout 源码及固定桥提交后编译；没有上传本地候选冒充 CI 产物。使用既有精简静态 Qt 6.8.1、静态 CRT/OpenSSL 和原生依赖，无 UPX、运行时 Python 或旁置 Qt DLL 要求。PE 导入核查只有 Windows 系统库。一次性 runner 已退出并移除，六个临时构建机仓库变量已删除，后续恢复默认 GitHub runner。

## 本轮产品修复

| 用户问题 | 实现与复用入口 |
| --- | --- |

| 未安装游戏不够醒目、版本字体过大 | 原 `SummaryButton` 空实例低频扫光；只在可见、窗口活动、无模态时运行。常规标题 24px DemiBold，紧凑 15px |
| 静音和任务结束导致视频重播、图标闪烁 | `BackdropCarousel` 比较播放列表地址内容，内容相同不清空媒体源；播放位置和播放器沿用原所有者 |
| Windows 拖动时播放卡顿 | 复用 `EdgeDock` 原有 16ms 松键轮询处理移动，避免系统阻塞移动循环；背景柔焦使用半分辨率采样 |
| 视频背景下吸附箭头不清楚 | 原 `DockHandle` 使用中性色图标，保留恢复外观和任务栏生命周期 |
| 任务、游戏身份、快捷账号菜单大片白底 | 统一复用 `DesignTokens` 媒体表面令牌和当前文字色；仅启用跨页背景时应用设置的蒙版透明度，关闭即恢复原样 |
| 按钮失去原有颜色、删除入口红色突兀 | 主按钮保留原紫色及白字；删除入口用轻量按钮，真正删除仍需原确认流程 |
| 设置入口未改名 | `SettingsPage`、`ToolDeck`、独立日志窗口均为“问题反馈与调试”，复用 `LogsPage` 与原反馈链路 |
| 开发版 / 稳定版 | 原设置持久化 `beta` / `stable`，默认开发版；开发版也接收稳定版。通过 `ApplicationLifecycle` 初始化和设置变化应用，切换取消旧渠道请求，不新增定时任务；保留服务端语义版本顺序及合法开发版后缀 |

已实际查看常规 / 面板的空实例、任务、身份、更新页，以及快捷账号菜单、首次约定和光影反馈弹窗。截图位于 `build/verification/media-release`、`first-run-layout`、`background`、`pack-round2`；无整窗模糊外沿，按钮可读，启用跨页背景时任务及身份表面不再是大片白底。
