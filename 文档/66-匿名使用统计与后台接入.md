# 匿名使用统计与后台接入

维护者需要了解使用人数和频率，用户明确只使用匿名标识。统计后台归统一控制服务 `https://node.bugg.icu/admin/statistics`，独立用户名和密码登录；启动器不携带后台凭据、联机昵称、角色名、游戏或模组清单。

## 唯一所有者与生命周期

检索 ApplicationLifecycle、GameRuntime 偏好、MultiplayerService 在线状态及 HttpClient：已有联机心跳在控制端足以统计鉴权账号，但无法覆盖未登录用户。因此只在 ApplicationLifecycle 新增可选 `attach_usage(HttpClient*, QUrl)` 装配和私有一次性 report_usage，不新增 worker、计时器、联网所有者或页面轮询。

GUI 装配注入原 HttpClient；首次须知确认、原 runtime / identity / multiplayer 初始化全部汇聚为 ready 后，每进程发送一次 `POST https://node.bugg.icu/v1/usage/launcher`。只有两项：随机安装标识 visitor、单次事件 event。5 秒超时，最多读取 1 KiB；失败不阻塞界面或启动，不无限重试。退出与取消统计沿原请求 ID 取消，迟到完成不能触发重发。

`GameRuntime::usage_identity()` 为 GUI 调用，初始化完成前/关闭期间返回空；随机 ID 保存进同一个 instance-settings.json 根字段 usageInstallationId，沿原异步写入队列持久化，不引入第二份配置。`anonymousUsage` 是原 preferences 中布尔项，默认 true；常规页沿 CheckOption 和 ToolDeck 的唯一偏好接线即时修改。QML 不实现采集。

## 口径与验证

匿名安装实例不是自然人数：复制便携目录可能相同，重装/清除配置可能重复，关闭统计/旧客户端不计。不能和账号数相加，不能把启动次数称为游戏次数。已登录账号的活跃天数、连接段与连接时长复用控制端真实会话租期；昵称不参与统计。

本地验证：实际生命周期确认前无事件，ready 后一次；关闭设置取消在途，重复 mounted 不重发；重开配置保持 ID，预先关闭统计无请求。GeneralPage 在 410 / 960 打开、切换并实际查看截图，控件和说明完整；qmlformat / qmllint / 组件边界门禁通过。原生单文件重新构建并更新固定 build/bugg.exe；本轮不覆盖已发布版本的不可变资产，未发布的客户端实例统计不能冒称覆盖所有旧用户。
