## 身份和启动

Main 注入 AccountPort/GameRuntimePort，IdentitySession/LaunchSession 保持既有唯一入口。微软身份使用真实设备码、Xbox/XSTS、Minecraft profile；本人在微软网页完成授权，读到真实角色才提交。离线切换保留微软会话，显式登出才清除；启动时后台恢复刷新凭据。Windows 用 DPAPI，macOS 用钥匙串；Linux 当前不持久保存刷新凭据，会明确提示。

离开设备码页取消当前授权，主题切换/折叠不取消；已取消响应不能替换身份。没有身份禁止启动，成功选择自动回流程入口。倒三角快速选择已有角色，无角色直接进身份页；其余区域进入管理。

点击启动原位呈现准备状态，不跳页面；锁定实例/身份。GameRuntime 统一准备文件/Java，最后归一化参数，创建真实进程后改 running 并清工具条准备进度。停止必须等进程退出。房间启动直接复用这些端口与流水线。

## 实例、安装与设置

Main.instances 只绑定 GameRuntime.instances。扫描用户选定目录的真实版本 JSON，忽略损坏记录；默认空列表。选择器、管理列表复用 ListRow；管理当前游戏进入 instance 详情，里面不放“启动游戏”。目录入口可明确选择已有 .minecraft，不隐式移动数据。

安装页从 InstallCatalogSession 读取 game/loader/loaderVersion/instanceName，发给 GameRuntime.install。安装、准备都复用 GameOperations/ResourceClient，校验缓存、逐源回退、原子落盘；失败/取消不提交半成品实例。任务保留在应用会话供重试，已校验文件跨启动可复用；任务快照由现有持久化保存，恢复不把中断任务伪装为运行中。

内存等游戏设置按全局默认与实例覆盖逐键合并，默认自动；每次启动器启动重新检测、游戏准备前再计算。编辑通过同一 GameRuntime 命令即时更新和异步保存，无保存按钮，页面不另存副本。PageStateStore 只放未提交的非敏感草稿，不能持有另一份设置数据库。Java 页显示真实候选路径，缺少兼容版本时由准备流水线下载，不编造已安装版本。细则见 [语言与即时设置](24-语言与即时设置.md)。

两种主题共用 ToolBar、ToolDeck 和全部页面。面板/收起工具条隐藏广场，NavigationBar.toolIds 保留 0/2/3 的实际身份；常规页保留 0/1/2/3。二级页面隐藏主菜单，复用 SubpageHeader 的返回和 Home。

## 目录缓存和不可用能力

目录沿用按来源排序/游戏/加载器隔离的缓存，启动后台读盘，访问检查有效期，先显示缓存再无感更新；失败保留有效列表，不清空闪烁。SelectField/ListRow 的悬停反馈统一维护。详见第 21 份文档。

好友、房间、同步、节点、模组内容、整合包导入等未接线时显示空/不可用，不伪造成功；内容/整合包安装不能误调用原版安装规格。测试专用 preview_enabled 默认 false，只供显式夹具走界面迁移。

PageStateStore 是窗口级草稿，不是设置数据库。业务结果和真实进度必须由所属服务发布；页面 Loader 反复创建不重建这些服务，不在回调捕获页面指针。验收结果见 [真实安装启动与生命周期流程](23-真实安装启动与生命周期流程.md)。

## 房间与好友呈现（2026-11-09）

唯一业务状态为 MultiplayerService.status。ToolDeck 只转发 create_room、room_command、social/invite_friend 等意图；创建/加入成功的 room_joined 才导航房间，发出命令本身不代表成功。好友短码、搜索歧义、申请/邀请/加入申请均来自 C++，页面不自行生成签名或处理响应。

房间复用 NavigationBar 的“聊天/成员”独立视图；当前视图和未发送草稿归 PageStateStore，消息/成员快照归 C++。聊天输入固定在底部；聊天/成员/缓存（访客为游戏）与复制邀请、邀请好友、启动游戏集中在上方；右上返回负责离房，左上 Home 保留房间回启动页；面板使用相同页面紧凑排列，不显示 IP/端口表单。世界未开放显示准备状态，启动仍走 LaunchSession 的身份拦截、原位进度和取消。房间设置草稿归 PageStateStore，保存成功才返回；无服务时安全加载空页面。

房间页头显示世界信息，Home 返回启动根页；常规首页摘要读取同一房间快照，点击返回房间不重建会话；面板不显示摘要，通过联机入口进入当前房间。未登录/授权失效隐藏好友入口，联机仍可重新登录；C++ 清除房间后不保留失效的 room/sync/settings 路由。

RoomChat 只组合共享输入、按钮和列表；发送确认才清草稿，失败保留文本。RoomSyncPage 只显示 GameRuntime 的 kind=room 任务，任务内的取消/重试是唯一入口；无任务时才显示“同步游戏”。同步发布实例并完成扫描后才绑定可启动实例，不用示例进度或固定文件数。

房主创建页的“加速缓存”复用节点 allow_mod_transfer 配置。缓存授权、计划和显式请求上传归 RoomContentCache；是否缓存及低速策略由源站决定，客户端没有速度阈值或低速回退。成员准备状态来自 GameRuntime 的真实任务，启动状态来自同一 LaunchSession，MultiplayerService 合并上报；切换聊天/成员不启动下载。房主未开放世界时，原连接状态位置显示黄色的暂停菜单“对局域网开放”指引，开放后显示绿色“本地世界已连接”。

缓存勾选不代表缓存成功。MultiplayerService 在建房及 configure 成功后保留 room.allowSharing，原生 describe 省略 allow_mod_transfer 时沿用已确认值；失败不提交新值。RoomContentCache 发布 cacheProgress 的 state/label/detail/active/done/total/progress/summary/cachedFiles，done/total 始终为当前上传批次的字节，summary 保留源站文件计数。缓存成功显示源站确认的文件名，页面仅展示前两个并归并剩余数量；不在 QML 复制文件清单或计算成功状态。RoomLobbyPage 复用 ProgressItem/ProgressSurface：等待时不定进度、上传时字节进度，ready/empty/unavailable 不绘活动条。关闭缓存、离房和退出取消同一 worker，旧代次进度不能恢复界面。

房间主按钮仅有一项：未匹配→同步安装，核对/准备中→过程状态，就绪→启动游戏，启动中→取消启动，运行中→游戏运行中。RoomSyncPage 在就绪后隐藏安装选项/已完成 TaskCard；重新选择实例清除当前准备绑定，后台重新匹配。业务判定仍归 MultiplayerService，UI 仅呈现已有快照。

好友分栏的选中 ID 归 PageStateStore 的 friends.selected，不能把选中好友的在线、房间等快照另存草稿；每次刷新均从 MultiplayerService.status 当前列表派生详情。宽窗口联系人点击只改变选择，右侧执行联机命令；面板/邀请页使用同一 FriendActions 行尾操作。无匹配项或删除后不保留过期详情，不显示未接入的私聊输入。聊天输入行下方安全留白由共用 RoomChat 提供，内部消息滚动不移动输入。

联机通知归既有 MultiplayerService.status：notifications/notificationCount/notificationAt 在 apply_social 和本地忽略后统一派生；首次收到时间及已读状态在同一快照保留，重复轮询不复活提示。FriendsPage 只组合一个服务号呈现项并按最近收到时间排序，同时间保留原顺序，不按在线状态排序。打开右侧通知视图或面板 notifications 路由后排队调用 mark_notifications_read，避免绑定计算期间同步改写快照；没有增加轮询 Timer、消息服务或网络入口。8 秒 heartbeat 是好友和大厅的唯一周期更新。rooms.page 只保存在 PageStateStore，Pagination 夹紧呈现页码，真实列表刷新不清空已有行。

## 2026-11-11 下载故障排查

HttpRequest.first_byte_ms 区分冷缓存首数据等待与数据空闲；HttpClient.transient_failure(id) 使 HTTP 200 下未完整文件进入原 ResourceClient 有限重试。diagnostics_status 暴露 busy/path/error，由 export_diagnostics(url) 驱动，失败不覆盖既有文件、取消沿原文件任务域。showOverlayInFullscreen 默认为 false，经 set_preference 原子持久化；仅 panel 置顶。桌面外部全屏检测目前实现 Windows，其他平台限制见第 46 号。

补充：微软授权归应用级 IdentitySession，切页、隐藏和吸附折叠不取消；只在用户明确取消或关闭应用时取消。新配置的默认外观为 small（紧凑），不覆盖已有主题偏好。NodesPage 的 routes/nodesBusy/nodesError/autoNode 归 MultiplayerService；手动节点影响下次新建房间，加入房间跟随房主，已有会话不强迁移。房间展示实际 nodeName、nodeLatencyMs 与 latencyMs，成员行保留 rtt_kind；大厅没有确定到同一节点的样本时显示待测。

LogsPage 的筛选和跟随开关为页面呈现状态；日志内容归 GameRuntime.debug_log。页面可见且跟随时 1.5 秒刷新，搜索 300ms 去抖；忙时不重入，离页停止轮询，完整日志仍走原诊断 ZIP 导出。
