# CurseForge 光影核心依赖选错（2026-11-12）

本轮继续核对用户的新报错：“Sodium 不兼容低于 1.12.1 的 Iris，当前 Iris 是 1.11.7+mc26.3”。这与第 50 号的旧 Sodium Mixin 崩溃是不同的失败组合。上一轮只处理了 Modrinth 精确发布例外，漏查了 CurseForge 直接安装核心时的依赖选择路径。

## 查到的实际选版错误

本地持久任务存在两次已完成的 CurseForge Iris 安装：目标 `26.3-neoforge-26.3.0.100`，主文件项目 **455508**、文件 **9015109**，Iris **1.11.7**；依赖项目 **394468**、文件 **9567621**，Sodium **0.9.3-beta.5**。该组合与用户新截图里的版本冲突吻合。

CurseForge 的 Iris 文件仅声明“必需项目 Sodium”，未给出其具体文件。旧递归解析器从该项目中选择了适配 Minecraft/NeoForge 的最新发布，错误地把“支持同一游戏版本”当作“与当前 Iris 兼容”。Sodium beta.5 的 JAR 清单明确排斥 Iris `<1.12.1`，因此这个选择不满足当前组合要求。

对照 Modrinth 同一 Iris 发布 **Ag5S66CF**，其必要依赖固定为 Sodium **VHtnT9Q4 / 0.9.2 for 26.3**。两平台 Iris JAR 的 SHA-1 均为：

```text
57cbbd1f58b6226c633520541c1a3ae57c019373
```

所以不是凭同名项目猜测映射。具体元数据、去敏任务记录和比较结果在 `D:/BuggBuild/version-followup-20261112/{cf-iris26.3.json,cf-sodium-beta5.json,historical-install-tasks.json,version-comparison.json}`。核对期间上述 NeoForge 实例目录已被移除，本轮不声称重新读取了新截图对应的当前 JAR，也没有恢复或改写玩家目录。

## 光影包本身也有要求

截图项目 Complementary Reimagined 的 **r5.9.3 / CurseForge 文件 8884654** 明确声明支持 **26.3 和 26.2**；r5.9.2 只声明到 26.2。完整支持列表中 `1.17.1 / 1.21 / 1.16.5` 是旧界面显示的前三个条目，不能据此判断整个文件只支持这三个版本。[作者具体文件页](https://www.curseforge.com/minecraft/shaders/complementary-reimagined/files/8884654)列出了完整支持列表。

光影包还声明 Iris/OptiFine 等加载方式。客户端要同时核对光影文件支持的游戏、光影加载方式、核心模组及其依赖；不能因为光影包支持 26.3，就推出任意 Iris/Sodium/NeoForge 组合都能运行。

26.2 的当前 Iris 发布是 **1.11.4 / k55HdONq**，指定 Sodium **0.9.2 / DmnNKsfS**。26.3 是另一套具体发布，不能共享选到的核心版本。原生只读核对结果见下方补充记录。

## 修复及复用

- 源站只在原核心候选清单登记 Iris 的 CurseForge 项目 **455508**，没有新增路由、数据库、下载器或静态版本替换表。
- `ContentProvider.core_release` 仅对已登记的 CurseForge 核心，复用原 SHA-1 → 发布查询确认同一 JAR、同一作者项目和两边明确声明的游戏/加载器，再复用具体发布依赖。主文件继续保留用户选择的 CurseForge 文件身份。查证失败时提示，不能静默回到最新依赖。
- 原 `resolve` 支持依赖自身的发布平台，沿用同一查询、递归、取消和上限；固定依赖失败不产出可安装的核心计划。同一 JAR 的坏组合例外同时适用于两平台入口。
- 原 `prepare_shader_install` 扩展并改名为 `prepare_content_install`，预检和实际安装都从实例读取实际加载器构建，再解析旧计划。普通模组也不能利用缺少 loaderVersion 的旧计划绕过规则。
- Iris/OptiFine 标签归为光影加载方式，不计入游戏版本；仅声明 OptiFine 的光影不会自动装配 Iris/Oculus。未知兼容性不靠版本号范围猜测。

本轮没有加入 TOML 库或第二套依赖解析服务。第 12、18 号启动器契约/方法清单和源站第 07 号契约已同步。

## 26.3 的边界

遵守作者固定依赖后，Sodium 0.9.2 仍与 NeoForge >=26.3.0.65 的已变更接口冲突。因此当前这套发布不能自动组成兼容的 26.3 NeoForge 光影环境，客户端应在安装前说明原因，不能把下载成功显示成组合兼容。

这不是全面禁止 Minecraft 26.3；例外限定具体项目、发布、加载器和构建范围。第 48 号 beta.1 临时修复只证明当时的有限隔离启动，不据此永久改写作者固定依赖，也不代表所有新构建、光影和模组的兼容保证。本轮不启动游戏、不做 FPS 或长期稳定性测试。
