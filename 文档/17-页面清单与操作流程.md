# 页面清单与操作流程

2026-11-10 任务明细：一次所选内容安装仍是一条任务，展开后逐个显示主内容及依赖的名称/版本/文件/状态/失败原因；可收起、内部有界滚动，面板不无限增高。缺依赖仍保留主内容并可重试，明细随原任务持久化。详情页显示“已安装 · 版本”；同文件校验一致不重复下载，仍可重新安装；升级/替换须确认已有文件，旧文件按原事务提交和回滚。

2026-11-10 广场安装：筛选默认折叠，摘要与数量共用一行，展开常规四列/面板两列；目录保持搜索与四类页签。详情主体为项目图文；常规右侧安装，面板“介绍/安装”切换，缺加载器进入匹配版本预选的创建流程。安装自动补齐 required 依赖；依赖失败仍保留所选内容，任务显示“待补齐依赖”、具名原因与“重试依赖”，明确缺依赖可能不能运行。重试补装原游戏，不重建或覆盖实例。

2026-11-10 广场：分类导航和搜索常驻，收起式筛选摘要显示当前版本/加载器/平台分类。首次进入自动跟随当前实例，四类资源分别获取真实分类，类别与版本/加载器求交。详情显示平台原始正文、插图和画廊；常规双列图文主体+安装侧栏，面板介绍/安装页签。安装目标与浏览过滤分开；不兼容可恢复目标筛选，原版或未安装游戏可引导创建兼容游戏并安装所选内容。创建与内容安装共用同一队列、隐藏事务及取消/重试，入口不新增整合包导入按钮，保留既有拖放导入。

2026-11-10 在线内容：广场共用模组/资源包/光影包/整合包目录，搜索、平台、目标兼容筛选及分页 → 详情 → 版本 → 必要依赖/目标预检 → 下载并安装 → 任务。实例内容页“在线添加”携带目标和类型；安装游戏页“查找整合包”进入同一目录。整合包新建实例并执行既有归档导入、Java/依赖准备和提交。取消、重试沿用任务，返回保留查询和选择。

当前补充：所有二级页顶栏共用“回到首页”图标，一次清返回栈并回启动入口；正常返回仍逐级。首页无角色时倒三角直接进入游戏身份，有角色时才开半透明快捷菜单。游戏选择行不随鼠标移入改变底色。

安装游戏页不再固定 1.21.1：首次进入请求真实正式版清单，默认最新正式版；五类加载器单选，按所选 Minecraft 请求兼容版本，默认最新稳定版，没有稳定版时标预发布。版本下拉共用可搜索 SelectField、按需列表，网络/解析不阻塞页面。切页保留版本和名称；刷新/错误重试复用同一 C++ 会话。开始安装提交 GameRuntime 的真实任务，取消/重试复用同一所有者。

## 导航与状态

- ToolDeck 中同一张表登记 route、中文标题和页面组件；openPage 拒绝未知路由，goBack 按栈返回。不要另写第二个页面路由器。
- 主入口切换清除子页返回栈；主题切换不清栈、不销毁当前页面。返回箭头与 Esc 使用同一 goBack，面板根页面再按 Esc 收回工具条；常规页面保持展开。
- 进入二级及更深页面，隐藏并禁用主菜单，最顶部仅返回/标题与窗口控件；返回根页再恢复主菜单。返回固定在窗口顶栏，内容不重复标题/返回栏；账号→离线身份等多层流程逐级返回。
- 切页重置滚动位置；长内容在顶部导航下方滚动，导航保持固定。主题切换的间距、导航尺寸和窗口尺寸由同一个进度驱动。
- 下载任务归 GameRuntime；来源优先级归 SourceSettings，统一默认 BUGG → BMCLAPI → 官方，页面仅转发上移/下移。无每资源类型的另一份顺序；切页保留，异步恢复/保存，不把下载或持久化写入 QML。
- 启动状态来自 Main.launchSession，准备/运行时游戏和账号选择隐藏并禁用；进度原位切换、保留背景和主导航。取消恢复，停止等待真实进程退出，失败可重试；离开首页不取消。无身份通过同一 preflight 阻止推进；真实执行由 GameRuntime/GameOperations/GameProcess 负责。
- 离线身份限制 3–16 位；未接线的导入、好友和反馈不能仅因表单有效便假报成功。跨页表单草稿归 PageStateStore，服务结果归 C++ 业务所有者。
- 身份确认后 identitySession 发 committed，离线/微软流程自动回原入口，首页和设置订阅同一状态。微软设备码需要用户在浏览器授权，读取真实 Minecraft 角色才成功；返回/取消使迟到结果无效。身份摘要头像和文字共用列中心线，长名称省略，不加宽窗口。
- 安装使用真实实例路径及重名检查；整合包和房间接入时复用同一规则，不能继续使用演示实例列表。

## 视觉和复用

功能页使用中性灰字、少量淡紫强调；单页一个主题，主操作清晰。设置首页为简短目录，外观与各配置独立成页；不重复绘制按钮或卡片。危险删除提示采用 danger 令牌与危险按钮。常规主题使用 960 × 600 的横向窗口和固定顶部导航，无独立菜单底座；启动页以整幅背景承载画面。

常规页面重新组织内容密度：表单主内容居中且最大宽 560；启动页参考游戏大厅的呈现，大幅风景背景、左下游戏摘要、右下账号与启动，导航融入背景，不堆卡片、活动公告或实例列表。点摘要进入选择页；选择后返回启动页，管理与任务在下层按需进入。账号入口进入游戏身份页。标题不在内容区重复；登录、身份选择、文件导入分步骤呈现。Java 手动路径仅在关闭自动后显示；来源调整即时生效并异步保存，不堆放保存按钮。

设置保持中性底色、单列对齐和必要留白；设置首页仅短名称与当前值，不重复放大标题，常规窗口下完整展示目录。内存自动模式仅展示本次建议和设备预算，关闭自动才出现编辑控件；语言和其他选择继续复用 SelectField，不新绘下拉列表。首页已有实例时只提供启动或选择账号，扫描期间显示加载状态；仅确认没有实例后提供安装。具体设置边界见第 24 份文档。

2026-11-08 最终按本次要求调整：顶部为启动、广场、联机、好友和设置图标，右上角收起/关闭；底部悬空菜单方案已替换。右上角收起回到工具条，避免无任务栏窗口最小化后找不到恢复入口。复用既有 WindowControls、ToolBar、NavigationBar、ListRow 与主题控制器，未引入另一套按钮或路由状态。

新增通用组件前检索了 PageHeader、SettingRow、SummaryButton、InputField、ChoiceCard 及旧启动器对应流程。已有按钮、输入、选择卡继续复用；新增 PageLayout、ListRow、FormField、ProgressItem、SubpageHeader、TextAreaField 只补足多页共同缺少的布局与控件。旧启动器仅用于功能盘点，没有复制旧样式或业务代码。
