# 首页交互原型与预览

> 2026-11-08：全新 QML 界面，原生 C++/Qt 6.8.1 + MSVC 2022 构建已运行。默认入口为 build/bugg.exe，身份与启动演示状态由 C++ 持有，已删除对应 Python 状态机。真实下载、安装、微软授权、联机及游戏进程服务尚未接入，不可把 UI 原型当成业务迁移完成。

## 形态

主导航为启动、广场、联机、好友和设置图标。双击预览入口默认打开常规页面；另可切换 410 × 76 的工具面板，点击需要的工具后展开内容，点击同一入口再收起。常规主题点击当前导航保持页面。同一主题宽度固定，长内容在顶部导航下方滚动。

设置 → 界面主题可切换两种呈现，共用同一窗口、工具条、页面实例和 DesignSystem：

| 主题 | 呈现 | 窗口与交互 |
| --- | --- | --- |
| 悬浮面板 | 内容在工具条下方展开为一体 | 宽 410，高度随内容变化 |
| 常规页面 | 标准顶部导航，内容在下方；右上角收起与关闭 | 960 × 600；小屏减少页面高度 |

2026-11-12 更新窗口规则：仅悬浮面板使用 Qt.Tool、置顶、不占任务栏并显示原生托盘；常规页面使用 Qt.Window，显示任务栏且不置顶。无系统托盘时保留任务栏入口。两种布局继续共用同一窗口和吸附/折叠逻辑，不另开侧栏窗口。「classic」是常规页面的内部主题标识。

顶部左侧为品牌和启动/广场/联机/好友，设置为图标，窗口控件在右上角。收起按钮回到小工具条，关闭按钮退出窗口；标题空白处可拖动。常规启动页使用整幅星轨背景，左下突出游戏名称与版本，右下为账号入口和启动按钮；点名称进入选择页，安装/导入/管理/任务入口均收在该下层页面。首页账号入口进入游戏身份选择，不伪造登录状态。紧凑面板仍保留精简的名称与启动组合。

## 动效

- 主题切换 420 ms InOutCubic，一条可反向中断的进度同时控制宽高、顶部导航尺寸和内容展开；不重建原生窗口。
- 常规启动根页使用本地背景，导航直接覆盖在背景上；功能页使用白色画布、细分隔线与下划线导航。背景淡出 180 ms，不自动晃动，不增加常驻粒子、动态模糊或运行时图片下载。
- 工具切换旧内容淡出 65 ms，稍停后新内容 230 ms 淡入；面板高度 360 ms OutQuint。子页进入 170 ms 淡入、位移 7 px。
- 折叠展开 260 ms OutBack（overshoot 0.6），收起 200 ms OutCubic，仅轻回弹一次；快速反向从当前进度续接，禁止再叠加长弹簧动画。
- 拉手用中性灰箭头和暖白底，无紫色边框或悬停色；工具栏没有 ToolTip，保留 Accessible 名称和键盘反馈。

## 页面与状态

5 个主入口、31 个子页面路由，清单与流程见 [17-页面清单与操作流程](17-页面清单与操作流程.md)。启动准备直接在首页底部呈现，不占独立路由；其他详细操作进入独立页面。选择游戏与实例管理共用 InstancesPage，选择模式选中即返回。设置首页只是简洁目录，主题/Java/来源/账号等各自进入子页。账号选择先区分 Bugg 与游戏身份，再进入对应登录表单。

返回箭头和 Esc 共用返回栈：子页最顶部显示返回和当前标题，主菜单隐藏且禁用；多层流程先返回上一级，回到根页后恢复菜单。面板主题根页再按 Esc 收回工具条；常规主题根页保持展开。切主入口清除返回栈；切换主题保留当前页面、实例选择和输入。切页重置滚动位置，避免下一个页面从中间打开。演示任务取消及来源排序在会话内保留；真实服务状态最终由 C++ 呈现模型持有。表单草稿目前仅在当前页面生命周期内保留。

主题选择目前也是会话状态；后续持久化由便携缓存目录内的 SettingsRepository 负责，禁止默认写 AppData 或 HOME。预览不实际删除文件、导出资源、发起下载或发送好友申请。

## 吸附与折叠

拖动 B 标志或工具栏空白处，靠近上、左、右边缘松手，28 个逻辑像素内以 260 ms 缓出吸附；角落可同时吸附两边，底边不吸附。向外拖动解除吸附，再次拖动中断旧动画。

右侧吸附在所有形态变化中保持右边缘固定；底部空间不足向上避让，收起恢复原纵向位置。读取当前屏幕可用工作区，处理负坐标屏幕和工作区变动。仅在拖动期间以 16 ms 定时器读取鼠标松开，不阻塞等待。

贴边后离开 900 ms 折叠，进入取消计时；文本或多行输入保持焦点时不自动折叠。点击 B 可手动折叠，点击拉手恢复原工具与输入。顶部拉手窗口 88 × 40，左右 44 × 88，真实缩小窗口，不用大块透明区域遮挡桌面。自由放置时不可折叠。

## 打开与查看

双击根目录「预览首页.cmd」打开原生 C++ 窗口，无需 Python。本机开发构建与运行：

```powershell
./tools/build_native.cmd
./预览首页.cmd
```

Qt SDK 默认在工作区 `.tools/Qt/6.8.1/msvc2022_64`，可通过 BUGG_QT_ROOT 指定。本机使用已安装的 MSVC 2022 和 Ninja。只编译本地原型，不生成或发布分发包。原生入口支持 `--theme classic|panel`、`--page identity` 和 `--capture 路径.png`。

可选录制工具仍可在 E:/code/bugg 执行（需先构建原生模型）：

```powershell
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py --theme classic
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py --theme classic --page sync
```

--tab 0/1/2/3/4 展开主工具，--page 指定子页路由，--capture 输出 PNG；--edge top/left/right 指定贴边，--folded 观察拉手。自动截图/录制使用软件渲染；正常预览用 Qt 默认图形后端。

无身份时首页主操作为“选择游戏身份”，不会开始准备；直接调用 start 同样被 C++ preflight 拦截并引导已有身份页。完成选择后主操作为“启动游戏”，演示身份→Java→文件→打开游戏四步，在原位置显示进度，支持取消、运行后停止；不会运行真实游戏。状态由 C++ LaunchSession 持有，切页/切主题保留。录制工具 `--launch-state preparing|running|failed` 固定状态用于截图。真实服务尚未接入，不能据此判断 Java、安装或启动业务已经完成。

游戏身份可走完整界面流程：离线身份输入有效名称→确认→自动回进入身份流程前的页面；微软模拟授权完成同样直接返回。首页进入就回首页，设置账号进入就回账号页，用户不用再点返回。已成功选择的微软身份与离线名称分别保留；切到离线再切回微软时，直接选用已保留身份并返回，不重复授权；切回离线预填原名字。取消或返回仍逐级退出并保留原身份，切主题和收起不丢当前流程。状态由 C++ IdentitySession 在内存中集中保存，关闭预览后清空，不读取/修改真实账号、凭据或配置。第三方登录与皮肤仍标为待更新并禁用。

```powershell
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py --record-theme 预览/工具条-常规页面切换.gif
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py --gallery 预览/全部页面总览.png
../buggcraft/.build-venv/Scripts/python.exe tools/preview_home.py --edge top --record-dock 预览/工具面板-贴边折叠.gif
```
