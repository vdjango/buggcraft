# 背景媒体、补装与下载来源

## 交付范围

本轮把背景展示、原版补装光影支持和下载来源放回现有所有者：`GameRuntime` 负责设置和目录扫描，`FloatingShell/WindowFrame` 负责展示，`BackdropCarousel` 只负责两层媒体切换，`BackdropMedia` 负责单个图片或视频，`ResourceClient/HttpClient` 负责实际路由快照，`ContentCatalogSession` 与 `GameOperations` 负责补装计划和依赖。

## 背景行为

- `backgroundOnPages` 默认关闭。开启后，首页仍使用首页效果，其他页面使用全屏模糊，模糊值按设置的 2 倍计算并保留控件可读性。
- 背景目录扫描最多保留 100 项，支持常见图片、`mp4/m4v/mov/webm/mkv`；扫描在 worker 完成，QML 不访问目录。
- 视频使用 Qt Multimedia 原生后端，通过同一个 `AudioOutput` 控制声音，默认静音；输出绑定系统当前默认设备，静音和音量一起更新，不靠重启视频生效。窗口隐藏、收起或游戏运行时暂停，切换或清空来源释放播放器。竖屏图片自动旋转为横向裁切，焦点略高于中心。
- 图片、视频和轮播只适用于普通页面外观。悬浮面板清空实际媒体来源并释放播放器；背景偏好保留，回到普通窗口后恢复。吸附条和面板不使用页面透明蒙层或白字配色，收起入口保留不透明底色。
- 视频解码不承诺跨平台硬件加速；本轮只确认 Windows Qt 6.8.1 的播放、暂停和恢复，未宣称游戏运行期间的 FPS 或所有编码格式兼容。

## 光影补装

原版目标打开光影详情后直接显示加载器和版本选择器，不再需要先点击入口。选择器变化会使旧计划失效，加载器目录完成后才提交同一目标游戏的完整计划；补装光影明确使用自动依赖，即使全局“自动解决依赖”关闭，也会在这条明确操作中解析加载器、光影核心及其必要依赖。安装仍调用 `GameOperations::install_with_content`，不会复制第二个实例。

## 来源显示

`HttpClient::route_changed` 在请求开始及允许的重定向时发布实际 URL，`ResourceClient` 将其归一为 BUGG、CurseForge、Modrinth、BMCLAPI 或官方并写入传输明细；任务卡和批次进度因此显示实际使用来源，而不是只显示发布平台。源站转发到上游后，来源会随重定向更新。

## 验收边界

本轮验证：Windows 11 x64、Qt 6.8.1、MSVC 2022；背景开关/双倍模糊/顶部进度、竖屏图片、真实本地 MP4 播放暂停恢复、原版光影补装状态和重定向来源单测通过，`qml_component_boundaries` 通过，并查看了面板与常规窗口截图。未执行所有游戏或整合包实机启动，也未宣称 macOS/Linux 视频后端或公网下载速度。

## 页面背景蒙层

开启页面背景后，`WindowFrame` 不再叠加实色页面底，而是保留全屏模糊媒体，并覆盖可配置的透明白色蒙层；默认透明度为 10%。设置页提供“其他页面白色蒙版透明度”（0%～30%）和文字颜色（白色/深色），两项只有勾选“将背景应用到所有页面”时才参与渲染，首页外观不受这两项影响。设置值由 `GameRuntime` 持久化，`DesignTokens`、`WindowFrame` 共用同一份偏好，避免各页面出现不同步。

## 加载器目录来源

游戏版本、Forge、NeoForge、Fabric、Quilt 的目录查询统一经过 `GameCatalogService` 和同一份 `SourceSettings` 顺序，默认 `BUGG → BMCLAPI → 官方`。BUGG 对应 `/maven/`、`/neoforge-maven/`、`/fabric-meta/`、`/quilt-meta/`；请求失败或返回无兼容版本时才进入下一来源，页面显示本次加载器目录的实际来源，避免把发布平台误当下载来源。

视频播放时，启动页工具栏在下载按钮旁显示声音按钮；`backgroundSoundEnabled` 默认关闭，点击后才创建可听的输出，切换页面、隐藏窗口或游戏运行时仍按原生命周期暂停。图片与视频共用同一目录清单和轮播器。


## Update package

The legacy update protocol continues to use /api/launcher/assets/<version>/Bugg-native-windows-x64.zip. The local v2.0.1 candidate includes both the single-file EXE and an update ZIP whose root ugg-update.json declares format 1, version 2.0.1 and platform windows-x64. The updater validates origin, size, SHA-256, root manifest and rollback. This is a local candidate; it has not been uploaded to the release service.
