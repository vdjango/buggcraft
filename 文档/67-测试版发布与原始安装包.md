# 测试版发布与原始安装包

2026-11-16 用户要求立即发布，今后默认只发测试版。v2.0.3 沿用现有五平台构建、发布和下载站同步入口；GitHub 必须 prerelease=true，下载站进入 beta。数字版本号用于原 CMake/Windows/Mac 版本资源，测试身份以发布渠道为准。

检索并扩展唯一打包器 package_release.py::main、LauncherUpdateService::download、下载站 validate_native_bundle/build_browser_packages/public_releases、官网 platformAsset。没有第二套下载器、更新器或服务，也不合并网站数据库和部署生命周期。

Mac 原始 ZIP 根目录为 Bugg.app/Contents/... 和 bugg-update.json；其余平台保留原目录。Mac 在现有更新 worker 中剥离唯一 Bugg.app/ 前缀，旧 Contents/ 目录仍可用，其他路径继续通过原安全校验。下载站只校验、存储和分发原始 ZIP；旧裸 EXE/ELF 才沿旧转换入口兼容。已发布附件不覆盖。

CI 必须用系统解压工具解开最终 ZIP，在移走构建 Qt SDK 后运行解出的应用和原生桥；Mac 另做应用结构及 codesign 检查。仅运行打包前目录不能算安装包可用。旧 Mac 2.0.2 不理解新的 .app 更新目录，发布说明要求手动下载；本地 1.0.0 测试包另行保留，不作为公开版本。

范围：官网、下载站、统一服务、源站独立部署，使用统计仅为可失败的外部请求。最终构建、部署与公网结果在本文件补记；不能把计划当成已经发布。

## Release candidate update

v2.0.3 was built for package diagnosis but not published. The final test release is v2.0.4, paired with native bridge v0.3.13 so authenticated startup usage works on all desktop platforms. Windows ZIP contains only bugg.exe; legacy raw-EXE URLs are derived server-side without recompressing or changing the original ZIP. Existing published 2.0.1/2.0.2 assets remain immutable.

User clarified that the leftover is a sibling file with a versioned name. The known historical alias Bugg-v1.1.0.exe and Buggcraft.exe are cleaned at the first update check only when bytes match this installation's current executable or a rollback executable bound by install.json. The current entry and unrecognized names are preserved. The download owner additionally detects actual ZIP content with is_zipfile and forwards its exact bytes even for historically mislabeled raw assets.
