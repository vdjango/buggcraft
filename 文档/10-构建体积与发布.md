# 构建体积与发布

## 10 MB 的真实口径

同时记录：C++ 主程序文件、Qt 动态库/QML 插件、原生 Bridge 及依赖、资源、完整解压目录、面向用户的 ZIP 体积。旧 Python 启动器主 EXE 约 48–53 MB；这只是旧版基线，不能拿来推算 Qt 版一定小于 10 MB。Qt 官方 [部署总览](https://doc.qt.io/qt-6/deployment.html) 说明：动态链接需随包交付相关运行库与插件；静态链接会使程序增大。使用 QML 还要部署实际用到的 Qt Quick/QML 模块，Windows 可用官方 [windeployqt](https://doc.qt.io/qt-6/windows-deployment.html) 汇集依赖。

**暂定目标**：主程序文件尝试 ≤10 MB；完整便携 ZIP 做最小原型测量后再定硬指标。不可依赖目标机器预装 Qt、隐藏从互联网下载运行库、删除联机组件或放弃便携配置来“达成”10 MB。若完整包确实大于 10 MB，公开实际数值，并就 UI 方案、功能及体积做明确取舍。C++/QML 不保证 10 MB。

## 原型量化步骤

1. 在固定 Qt 6 次版本、同一编译器和同一目标架构下，构建极简 C++/QML 窗口 + 设计系统 ActionButton/Surface + 任务列表模型，测启动响应和中文字体。
2. 用 qt_add_qml_module 打包/编译 QML，CI 检查 qmllint；分别测含/不含预编译的产物大小及启动速度。Qt 官方 [QML 模块和预编译说明](https://doc.qt.io/qt-6/qmldiskcache.html)。
3. 加入 Qt Network、账号流程、原生 Bridge，生成依赖清单；按模块归因增量体积。标出 Qt 运行库、平台插件、TLS、原生 Bridge、第三方压缩库分别占多少。
4. 对 Windows x64、Linux x64/ARM64、macOS Intel/ARM64 各自测主程序、解压目录、ZIP；不同平台不得用单个数字代表全部。
5. 若超预算，先删未使用模块/素材/调试符号、压缩资源、检查部署扫描，不盲目静态链接或塞 UPX。任何体积优化都必须保留完整可运行性与安全校验。

## 构建和依赖

- C++20、CMake 预设、固定 Qt 次版本和编译器范围；依赖版本与 SHA 固定，不从浮动 main 拉原生 Bridge。其低频更新的已发布二进制按平台复用，只有 Bridge 源码或 ABI 变化时单独构建它。
- 每个模块一个 CMake target，contracts 不依赖 UI，core 测试不加载 QML。qt_add_qml_module 集中登记页面和共享组件，实际只引入用到的 Qt 模块；不引入 Qt WebEngine。
- 构建产物按平台生成，保留 Qt 与 Bridge 许可材料并审查 AGPLv3 项目与所选 Qt 模块许可证的分发要求。Qt 官方 [许可总览](https://doc.qt.io/qt-6/licensing.html) 提醒不同模块许可未必相同；静态/动态链接的合规性需在发行前专项核对。
- 应用使用相对路径，不假设开发机 Qt 安装目录、编译器 DLL 或 HOME 下文件在玩家机器存在。

## CI 与发行顺序

格式/静态检查 → 离线确定性测试与契约测试 → 平台编译 → 打包、生成 SHA 与体积清单 → 发布构建产物。打包后不追加重复测试；网络不可达导致的远端下载测试可标记跳过，不阻断与该网络无关的构建。缓存工具链、Qt 依赖与不变的原生 Bridge 包；版本升一级才推送标签。正式发布可复用已通过主分支 CI 的同一产物，不重复编译。

下载站五个平台都给用户 ZIP：Windows ZIP 内含 EXE、Qt/Bridge 所需运行文件；macOS ZIP 内是可打开的 .app；Linux ZIP 内保留可执行位与链接（若 ZIP 工具不能可靠保留，则改用受控安装结构并提供解压说明）。内部自动更新可以使用不同于浏览器入口的经校验资产，不把裸 EXE 冒充下载站 ZIP。下载页展示压缩包大小与哈希。

本轮 Windows x64 实测结果、运行时依赖边界和安全打包流程见[启动器打包体积与误报实测](42-2026-11-11启动器打包体积与误报实测.md)。本机证明完整 Qt + 联机桥离线包约 20.22 MiB（7z），低于 50 MB 基线但高于 10 MB；详细数字只适用于该环境，其他系统须分别构建测量。

后续已实际自编译精简静态 Qt，见[自编译精简Qt实测](43-2026-11-11自编译精简Qt实测.md)：同源码对照 7z 从 21.20 MB 降到 16.21 MB，ZIP 从 32.12 MB 降到 23.32 MB，解压目录 52.80 MB。静态版主 EXE 为 30.35 MB，内含 Qt；不能和动态版 7.73 MB EXE 单独比较。配置所有者为 `cmake/SizeOptimization.cmake`，Qt 源码构建入口为 `tools/build_size_qt.cmake`。该配置默认关闭，Windows x64 样包尚未签名和正式发布，不代表其他系统已经验收。

最新本地完整样包见 [44-按需语言包与单背景体积实测](44-2026-11-11按需语言包与单背景体积实测.md)：其他语言按需获取，默认保留一张背景；7z 14.22 MB、ZIP 20.91 MB，均含桥和运行库。功能/两种主题/Defender 本地验收通过；语言附件尚未上传、未切换固定入口，未签名和正式发布，不等于公网已上线。
