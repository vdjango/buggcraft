# 启动器生命周期与资源管理

2026-11-11 下载修复契约（针对性回归通过）：GameRuntime 启动准备与后台安装分别持有任务 ID/取消令牌。启动已有且未被当前内容安装修改的实例不受无关下载阻挡；进度、完成、取消核对各自 ID，退出取消两者并沿 workers_/drained 汇聚。整合包外部资源与基础安装有界并行，共享文件仍原子校验提交。

2026-11-10 内容项进度：ContentProgress 复用 GameRuntime 原 operation worker、watcher 和 Cancellation，未增加线程、定时器或下载所有者；queued 回调同时检查 closing/cancelled/task_id，阶段终态立即投递，高频进度沿用 100 ms 限流。明细只合并有界快照，不逐进度写磁盘；终态由原 persist_tasks 保存，恢复时活动项标记 interrupted，已安装/已完成项保留。文件哈希在 worker 进行，GUI 不读盘。

2026-11-10 在线内容：应用持有 ContentCatalogService，窗口持有 ContentCatalogSession。页面和主题销毁不重建业务状态；关闭取消会话，ApplicationLifecycle.attach_content_catalog 纳入 shutdown/busy/drained 汇聚。HTTP、依赖和 JSON 在 worker；GUI 只接有界快照。取消或来源变更使旧结果失效。安装继续归 GameRuntime 同一队列和取消令牌。

这是每次开发及新聊天必读的公共约束。实际协调器为 src/app/ApplicationLifecycle；流程图见 [真实安装启动与生命周期流程](23-真实安装启动与生命周期流程.md)。原生入口已经接入，禁止页面自行初始化 Java、恢复凭据或收尾任务。

房间缓存与进度上报补充（2026-11-09）：缓存 worker 归 MultiplayerService 持有，切页/Home/折叠不中断；离房、关闭缓存授权、游戏配置变化、登出和退出触发取消。配置改变先释放旧 worker 再建新任务，progress 受 Cancellation 与 room_generation 约束。退出等待既有 drained 汇聚，GUI 不等待网络或哈希。member_update 合并计时器也归同一服务；离房清空当前任务/待发送内容，禁止迟到结果恢复房间。

2026-11-10：launch_progress 始终保存最近启动快照，建房不要求停止正在运行的游戏，但 preparing/running/stopping 期间不能换实例。clear_task_history 只清理终态展示和重试规格，沿用现有任务持久化，不取消活动队列。生产入口不再强制 QML_DISABLE_DISK_CACHE=1，允许 qt_add_qml_module 的编译缓存生效；源码 UI 测试仍显式禁用缓存以验证当前文件。测试创建的游戏必须在失败和成功路径都清理，包括建房前已启动、尚未收集窗口句柄的游戏；只能清理本次测试启动器的子进程。

## 钩子与触发点

原生更新由应用持有 LauncherUpdateService，ApplicationLifecycle.attach_updates 汇聚 shutdown/busy/drained。首帧后只异步检查一次，不加入 ready 的等待条件；至多一个检查请求和一个可取消 worker。关闭取消 HTTP/下载，迟到 queued 进度不得恢复状态；worker 排空前不销毁所有者。用户点“重启并安装”后，启动暂存目录中的独立原生助手，再复用既有 shutdown；只有助手可等待旧进程退出及替换文件，GUI 不等待进程。缓存迁移复用原 cache_root_changed 信号，不为更新新增线程池或定时轮询。

| 钩子 | 触发点与职责 |
| --- | --- |
| setup | app 装配服务、建立默认快照；不扫描/联网等待 |
| before_mount | QML 创建窗口前注入账号、目录、设置与游戏服务 |
| mounted | QQuickWindow 首帧 frameSwapped，幂等一次；开始后台初始化 |
| initializing | 并行恢复凭据，检测内存/Java 路径、读取配置、扫描实例 |
| ready | 初始化所有者均返回之后；局部失败记录错误，其他能力继续 |
| before_update / updated | 路由/工具/主题标识变化；携带旧/新标识，下一事件循环确认更新，不是逐帧回调 |
| deactivated / activated | 隐藏、最小化、收起、边缘折叠及恢复；只暂停呈现动画 |
| error_captured | 初始化/凭据保存失败；记录所有者和可读原因，不记录令牌 |
| before_unmount | Main 唯一关闭入口；隐藏窗口、拒绝新任务、取消自有准备及授权 |
| unmounted | 工作任务和串行保存结束后发 quit_ready，退出事件循环 |

这是应用与保留视图的生命周期。Loader 页面创建/销毁归 Qt 对象树；页面不拥有账号、下载或进程。未来页面级订阅在创建/销毁时订阅/退订已有服务，不重复应用 mounted。

## 唯一所有权

| 寿命 | 所有者 | 结束语义 |
| --- | --- | --- |
| 应用 | main 持 HttpClient、GameCatalogService、SourceSettings、MicrosoftAccount、GameRuntime、LanguageService、ApplicationLifecycle | 有序退出后逆序析构 |
| 窗口呈现 | WindowController、EdgeDock、ToolDeck、PageStateStore | 切页/折叠保留，窗口销毁释放 |
| 身份 | MicrosoftAccount 持凭据；IdentitySession 持非敏感呈现 | 切离线不登出微软，显式登出清受保护存储 |
| 安装/准备 | GameRuntime 调度 GameOperations、ResourceClient | 完成/失败/取消确认，离开页面不取消 |
| 游戏 | GameProcess 监视启动器创建的 PID | 停止等真实退出；关启动器只解除监视 |
| 目录缓存 | GameCatalogService/CatalogCache | 异步读取、来源隔离、串行保存 |

房间启动经同一个 LaunchSession 调用 GameRuntimePort.launch，房间同步复用 GameOperations 的文件准备；不得另写房间专用下载器、参数拼装器或 Java 选择逻辑。

## 首帧与自动内存

首帧前只建对象与窗口，不扫描磁盘、不运行 Java、不等待网络。首帧后 GameRuntime.initialize 在工作线程读取物理/可用内存、便携配置、Java 路径，再异步扫描真实实例；扫描完成才报告 runtime 初始化完成。

只保存 automatic/manual 策略和手动值，不保存自动计算结果。每次启动器进程启动都重新检测；准备游戏时在工作线程再按当前可用内存计算。缺少兼容 Java 时下载 Mojang 对应运行时、验证版本，然后使用绝对路径；Forge 处理器也用同一路径，禁止裸 java 回退。

2026-11-09：实例扫描同时产生活动模组数；启动 worker 仍重新计数并采样，不把初始化结果固定到所有启动。手动添加 Java 使用同一 run_file_work/java_major，验证前不保存；按实例的选择代数挡住迟到验证。QML 身份快照在设置命令边界转成 QVariant 值再检查和保存；初始化先恢复身份，再打开自动保存门，避免恢复中间态覆盖磁盘。

默认目录为应用目录/.minecraft；用户可明确选择已有目录，重扫 versions，不隐式搬动或删除旧游戏。正常入口无示例实例。

初始化同时恢复 GameRuntime 的全局/实例设置和通用偏好。LanguageService 订阅语言偏好，原位重译，不重建会话。真实实例首次扫描完成前，首页保持加载状态，不能提前显示“安装游戏”。运行中目录变化由 GameRuntime 的目录监听合并后复用后台扫描；新增空目录继续监听，不能遗漏稍后生成的版本 JSON。退出停止监听调度，沿用已有任务取消和串行保存收尾。语言、即时设置与内存编辑的完整契约见 [语言与即时设置](24-语言与即时设置.md)。

## 操作与取消

| 操作 | 保留 | 取消/释放 |
| --- | --- | --- |
| 切页、回首页、切主题 | 身份、准备/安装、选择、草稿 | 旧页面呈现 |
| 离开设备码页 | 已确认身份 | 当前授权/轮询；迟到响应失效 |
| 折叠、边缘吸附 | 路由、任务、游戏 | 隐藏时暂停背景/水纹 |
| 微软登出 | 离线角色 | 微软记录、令牌及受保护存储；启动期间界面锁定 |
| 取消安装/准备 | 已校验缓存、原实例 | 传输/后续处理器，确认后结束；不提交半成品 JSON |
| 停止游戏 | 配置、实例 | 异步关闭自有 PID；等真实退出，不杀所有 Java |
| 关闭启动器 | 已运行游戏 | 取消自有任务/授权，异步汇聚保存后退出 |

GUI 不调用哈希、解压、Java 扫描、网络等待或 waitForFinished。工作线程中的受控 QEventLoop 只服务本线程 Qt Network；取消标记短周期及文件边界检查。工作捕获值，queued 进度回应用所有者，不捕获 Loader 页面。退出先取消再等待异步完成，不能在 GUI join。

GameOperations 的进度合并在原 worker 对象内完成，不积累跨任务缓存或新增 GUI 定时器。每次 report 先检查取消再决定是否发出；GameRuntime 的任务终态始终即时发布，不能依赖最后一个中间进度来清理任务或房间状态。

窗口仅在生命周期尚未 stopped 时拦截关闭并启动收尾；quit_ready 发出后的最终关闭必须放行。否则 QGuiApplication 的退出事件会被同一个 onClosing 再次否决，留下没有窗口的后台进程。原生窗口关闭回归必须验证进程真的退出，不能只验证窗口隐藏或钩子已发出。

请求带 ID/代数；取消、登出使旧响应失效。不能仅凭“仍是 authorizing”接收上轮授权。创建进程与取消竞争时必须处理真实 PID。配置串行合并最新值，草稿不能覆盖已提交业务快照。

## 呈现与目录资源

BackdropCarousel 属于窗口背景，只在可见启动根页轮播；两层异步解码，坏图有界跳过并保留可用图。收起是无背景的工具条。ProgressSurface 由菜单和下载列表共用，仅消费真实 activity，动画不推进业务。

SourceSettings 管统一源顺序；切源通过既有会话刷新目录，在途文件任务保留启动时的来源快照。目录缓存、组合请求和取消契约见 [游戏目录与多源适配](21-游戏目录与多源适配.md)。

新增异步能力必须登记所有者、线程、初始化、取消/迟到、切页保留与退出收尾，并更新方法索引。UI 过组件边界门禁；无身份不能启动，实际进程创建后才清准备进度；preview_enabled 仅限测试。

## 节点与吸附补充（2026-11-09）

MultiplayerService 属于应用寿命：切页、主题和折叠不销毁节点或房间。离开房间清空待邀请与发送状态，递增房间代数；迟到建房响应关闭其会话，迟到邀请/加入结果不得重新入房。登出和退出另递增登录代数，取消查询及队列；NativeBridge 异步排空，不阻塞 GUI。

已吸附且鼠标离开时必须自动折叠，输入焦点不能锁住展开状态。HoverHandler 为即时通知，120 ms 系统指针读数补偿原生移动丢失事件，复用既有 900 ms 延迟和 setFolded 动画；未吸附、拖动中或已折叠时不进行该轮询。隐藏窗口的指针读数为 false。

房间事件轮询与加入者 LAN 广播归 MultiplayerService，切到首页/好友或折叠继续工作；离房、登出、退出停止计时并清理消息。房间已停止时清除摘要和路由，不保留失效句柄。节点授权到期前五分钟复用设备签名续期；有效凭据遇临时网络错误延后重试，过期/撤销进入可重新授权状态。已有房间持有的旧节点句柄等离房后释放，不在续期时中断会话。

内容同步复用 GameRuntime 的工作队列与取消标记，NativeBridge 请求在 GUI 投递，等待只在 worker。取消/离房后清单或传输迟到回包不得提交旧房间结果；同步发布真实目录后，等实例扫描完成才发 room_prepared，启动仍走同一 LaunchSession。详细输入/失败规则见第 12、22 份文档。

房间 config_id 改变与离房均使候选检查和未完成准备失效：MultiplayerService 发 content_invalidated，GameRuntime 复用 cancel_task；room_progress/room_prepared 携带 config，content_checked 带检查代次，服务仅接收当前身份。准备完成后不自动启动；显式启动经同一 LaunchSession 和 prepare 的最终房间文件核对。切聊天/成员/缓存不取消任务；Home 保留会话，右上离房返回才取消。

受管联机沿用 MultiplayerService 的 GUI 代次、取消和授权恢复，NativeBridge 工作线程调用同一原生 ControlClient。登录 URL 为控制 origin；分配和节点恢复不在 GUI 同步运行。HttpRequest.ca_pem 只归请求对象及其 QSslConfiguration，不修改全局 CA，不保留用户私钥或管理员凭据。

2026-11-11：语言下载也归 ApplicationLifecycle：attach_languages(LanguageService*) 连接 drained；shutdown 先取消语言工作，drain 以 busy 为屏障，禁止 GUI 同步等待。切语言/缓存搬迁使旧结果失效。默认仅一张内置首页背景，BackdropCarousel 保留用户自选多背景能力，单图时不启动轮播。详见第 24 份契约。

## 2026-11-11 诊断与窗口生命周期

platform/diagnostics 在内存收集有界脱敏事件，checkpoint 沿原 settings 文件 worker 落盘，export_diagnostics 沿 run_file_work 取消域与原 workers 排空。日志页仅选择目标与展示结果，不扫描磁盘。WindowController 全屏轮询在 closing 后停止，隐藏入口由同一控制器恢复；EdgeDock 不在隐藏窗口处理鼠标折叠。详细契约见第 46 号。
## 2026-11-11 下载与启动协调补充

`GameRuntime` 在 GUI 线程保存待启动意图与被暂停任务 ID；同实例内容写入复用原任务取消令牌，worker 退出前不启动游戏，不在 GUI 同步等待。worker 完成回调核对启动代次；启动取消、关闭和过期回调不再触发待启动意图。暂停任务保留原规格重新排队，运行游戏时队列跳过同实例写入，进程退出后恢复原调度。其他实例下载不共享启动取消令牌。

日志视图刷新复用原文件 worker/关闭排空路径；过滤参数只作文本条件，不能指定任意文件。后台生成有界脱敏值快照，GUI 发布信号；页内定时器只在可见且跟随时请求，关闭后忽略迟到结果。Microsoft 授权属于身份会话，导航/折叠不拥有其取消权；显式取消和应用关闭仍沿用原取消路径。


2026-11-12：原生托盘由唯一 WindowController 持有，closing 后隐藏；恢复复用 selectTheme/showNormal，退出走原 onClosing，不新建窗口、账号或任务会话。ResourceClient 的 100 ms 文件/校验节流与 500 ms 等待更新在原 worker 完成，阶段边界立即发布；GameOperations 不重复节流这些已合并状态。成功导航信号只在非关闭、无错误/取消/缺依赖时发出，UI 不从进度百分比猜测安装完成。日志固定视口仅实例化可见列表行，读取仍有界 256 KiB/文件、500 条结果，不解析整个大日志或在 GUI 扫盘。

## 2026-11-12 续传生命周期

暂存和锁归单次 HttpClient 文件请求持有。取消先撤销 ID 再 abort，释放句柄/锁但保留未完成暂存，不提交目标或发迟到成功。前缀恢复/完整提交只在原 worker 按块处理事件并检查有效性，GUI 不读盘或等待。非文件 HTTP、上传、OAuth、无摘要请求不变；分段仍归原父取消域，不另建队列。
