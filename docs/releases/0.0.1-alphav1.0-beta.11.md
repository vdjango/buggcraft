# Buggcraft 0.0.1-alphav1.0-beta.12

- 适配联机节点的邮箱验证账号和重名账号选择，好友查询保留完整账号 ID，避免把同名玩家识别为同一人。
- 改进好友邀请、加入申请、房间创建与开放世界的进度提示，支持同时邀请多位好友，并增加消息提醒。
- 修正原生联机组件的错误诊断，区分组件缺失、架构不匹配、权限拒绝和 Windows 应用控制拦截。
- 更新原生联机运行库，修正短时间内连续好友操作的签名顺序。
- 改进首次引导、游戏语言、下载任务与自动更新退出流程。

联机账号请先在节点网页完成邮箱验证或选择已有账号，再领取个人启动器接入码。已有节点可直接更换接入码。

Windows 下载 `Buggcraft.exe`；Linux 按架构选择 `Buggcraft` 或 `Buggcraft-linux-arm64`；macOS 按芯片选择对应 ZIP。校验值见 `SHA256SUMS-*.txt`。

此版本使用 beta 更新通道。Windows 包暂未进行受信任的代码签名，macOS 包使用 ad-hoc 签名。
