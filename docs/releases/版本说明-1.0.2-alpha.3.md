# Buggcraft 1.0.2-alpha.3

- 联机大厅首次使用显示“节点登录”。点击后打开统一的节点登录窗口，填写节点地址并在浏览器授权，连接验证完成后自动返回大厅。
- 节点登录窗口沿用原有登录流程，移除左侧节点列表；首次登录、切换节点和重新验证账号使用同一个入口，重新验证时恢复当前节点的地址。
- 大厅直接显示当前节点的地区或名称及连接延迟，替代节点下拉框。节点地区会随登录信息保存，重启后继续显示。
- 关闭登录窗口会取消正在等待的授权，避免关闭后继续跳转浏览器；浏览器未能打开时仍可复制链接或重新打开。
- 更新大厅新手引导及相关界面回归检查。

此版本为开发测试版，使用 beta 更新通道。
