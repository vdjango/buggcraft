# Buggcraft 1.0.2-alpha.4

- 联机统一自动连接：优先尝试 P2P，无法直连时自动通过节点中转。大厅、创建和加入房间不再提供连接方式选择，实际连接状态仍清晰可见。
- 登录后及每次启动时，在后台测量联邦节点延迟，自动分配可用的低延迟节点；大厅可查看节点地区、实测延迟和当前线路，手动切换无需重新登录。
- 手动选择在本次启动期间保留；离线节点隐藏，节点不可用时自动回退。已有房间期间禁止手动切换，避免中断联机。
- 统一节点登录和切换窗口的紫色面板、标题栏、字体及按钮样式，改善新手引导与账号重新验证流程。
- 改善启动阶段的后台初始化与下载源请求处理，减少界面卡顿和无效重复请求。
- 更新配套联机组件至 0.3.11；四个平台直接复用已发布运行库，减少重复编译。

此版本为开发测试版，使用 beta 更新通道。请从 [下载站](https://download.bugg.icu) 下载对应系统的 ZIP 压缩包，完整解压后运行。
