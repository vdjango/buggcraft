# Buggcraft 1.0.1-alpha.2

- 联机节点统一使用域名或 IP 地址接入，并通过浏览器登录；移除启动器旧接入码入口。授权成功后自动返回大厅，改善登录等待与账号切换后的好友同步。
- 大厅补充当前节点、地域和线路信息，改进网络类型探测、P2P 会话统计与连接恢复。
- 游戏和加载器默认使用 BMCLAPI，模组与整合包默认使用 Modrinth。支持自动测速及切换来源，增加 MCMirror；下载列表直接显示当前下载源。
- 下载失败最多自动重试 6 次，复用已校验文件并支持续传；切换下载源立即生效，候选来源全部失败时说明具体原因。
- 修复下载已显示完成但安装仍未结束、速度显示不及时，以及安装结束后页面未重置的问题。
- 修复部分电脑即使已在 Java 管理中下载 Java，安装 NeoForge 时仍因 Java 路径为空而失败的问题。Forge / NeoForge 安装前会自动选择兼容的已安装 Java；缺少时下载到启动器缓存目录，失败时给出明确提示。
- 加载器安装最终只生成一个实例文件夹，按“MC 版本-加载器-加载器版本”命名。下载游戏、下载整合包和导入整合包遇到重名时，先确认新名称或取消，保护已有文件。
- 精简导出按哈希查询 Modrinth 与 CurseForge：确认能够下载的模组使用下载链接，未发布或无法下载的模组随包保留。常规导出保留本地文件；导出窗口显示进度并支持取消。
- 配置、下载缓存、Java、启动器运行库、临时文件与日志统一保存在设置的缓存目录，默认使用启动器旁的 `.buggcraft`。支持重启迁移与整个文件夹搬迁，不再默认写入系统用户目录。
- 首次启动时，启动器同级 `.minecraft` 不存在则自动创建并设为默认游戏目录；已有目录和用户选择保留。
- 删除实例与游戏文件夹时，高亮提示“永久删除、会删除本地文件、无法撤销”。实例默认删除本地文件，也可选择仅从启动器移除并保留文件，随后恢复显示。
- “提交诊断”调整为“反馈问题”，直接输入问题内容，并说明自动收集的环境与日志信息。

这是开发测试版，可在启动器设置中选择“开发版”接收更新。整个启动器文件夹可一起打包搬迁；跨电脑使用时需要重新登录账号，外部游戏目录或外部 Java 需要另行携带或重新选择。
