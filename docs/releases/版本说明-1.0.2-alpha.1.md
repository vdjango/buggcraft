# Buggcraft 1.0.2-alpha.1

- 房间同步改为缺失文件队列：个别模组失败时继续下载其他文件，最多自动补齐六轮，重试仅处理未完成文件，复用已校验文件和有效断点。必需文件未齐全时不会误报完成或启动游戏。
- 新增房间临时下载加速：先提交文件信息，正常来源直接下载，仅为缺失或持续过慢的文件按需缓存。公开下载不要求账号；节点只验证文件提供权限。需要节点和源站启用对应服务，旧节点保留原有下载方式。
- 整合包导入、下载复用缺失文件流程，并可按哈希从已配置的源站补齐已有临时文件，无需重新下载成功资源。
- 房间共享设置改用“文件共享与临时下载加速”，明确说明通常保留 8 小时和公开获取风险；缓存清理在后台处理，不向玩家显示清理倒计时。
- 房间自动下载不尝试 Modrinth、MCIM；设置提示 Modrinth 速度极慢、MCIM 不推荐。已有相同文件的 CurseForge 地址不再为测速额外查询 Modrinth，保留手动选择入口。
- 修复大模组清单创建/加入房间时原生桥参数超过 8192 字节的问题，并在配置准备前检查缺失目录和版本信息，避免 NoneType 路径异常。

此版本为开发测试版，使用 beta 更新通道。
