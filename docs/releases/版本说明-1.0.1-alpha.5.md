# Buggcraft 1.0.1-alpha.5

- 下载记录和文件进度改为按行更新，合并高频进度通知；任务开始、结束与周期性保存均在后台写入历史，减少下载游戏、整合包和房间配置时的界面停顿。
- 启动时延后后台联机初始化与更新检查，联机大厅按需加载；没有运行游戏时不反复执行局域网世界扫描，避免挤占好友与房间请求。
- 保持登录的节点设备主动续期；认证请求暂时失败时先自动恢复，在线房间不再被重新登录弹窗打断。明确收到设备授权撤销后保留重新登录入口。
- 加载器的隔离安装目录直接复用游戏目录的公共缓存。多个整合包同时安装时，相同依赖库和原版资源按文件加锁、校验后共享，减少重复下载；取消安装后已完成的公共文件继续保留。
- 修复 Windows 下 Forge 名称大小写导致正式版本目录被误当作中间文件删除的问题，解决部分整合包安装末尾出现 `WinError 2`、点击继续安装仍失败的问题。

此版本为开发测试版，使用 beta 更新通道。Windows 包暂未进行受信任的代码签名。
