# Buggcraft 1.0.1-alpha.4

- 优化首次使用引导，统一卡片、重点文字和操作提示，完善房间教学及结束退出流程。
- 房主可以先创建准备房间、选定游戏，再随时进入世界；玩家可提前安装所需客户端，房主可以查看准备进度。
- 调整房间布局，聊天优先展示，成员列表提供连接方式、延迟和房主管理操作。玩家授权后，房主可以查看其安装日志协助排查。
- 支持导出与导入 Buggcraft 整合包，提供精简、常规两种导出方式。
- 房间客户端优先使用设置中的下载源，已建立直连时可回退到房主传输；资源包、光影可按需同步。
- 完善游戏下载、模组、资源包、光影和整合包的进度、速度与日志展示，支持设置并发下载数量。
- 游戏调试日志支持颜色区分、搜索和筛选，异常退出时保留实际退出码。
- 修复界面回归中的滚动后点击、房间搜索后操作和游戏启动回执问题。

这是开发测试版，可在启动器设置中选择“开发版”接收更新。
