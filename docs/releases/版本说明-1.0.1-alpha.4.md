# Buggcraft 1.0.1-alpha.4

- 启动前按实际 JVM 内存和已启用模组数量检查风险，沿用启动器弹窗提示；可返回调整，也可选择“仍然启动”。
- 修正设置项单选组允许全部取消的问题；房间只显示在线成员，并整理房间信息、操作按钮和加入中的进度界面。
- 降低游戏、整合包、模组与资源包下载及房间同步时的界面刷新频率，合并文件进度更新，减少卡顿。
- 房间存在失效的好友在线状态时，自动重试普通在线状态，避免好友列表整体变为未知。
- 更新反馈上传桥接与节点的错误处理：节点异常会返回可识别响应，桥接层显示节点拒绝原因；两台联机节点已同步服务端修复。

此版本为开发测试版，使用 beta 更新通道。Windows 包暂未进行受信任的代码签名；安装前请保留现有启动器和游戏目录备份。
