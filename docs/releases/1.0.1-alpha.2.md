# Buggcraft 1.0.1-alpha.2

- 统一首次使用引导与启动器页面的视觉层级，首步设置、重点词和点击/Enter 操作均有明确高亮。
- 修正联机房间引导在页面切换或目标控件暂时不可见时提示消失的问题；现在仍可点击“继续”或按 Enter 完成教学。
- 增加引导卡片和联机房间尾段的 UI 回归测试，覆盖真实大厅控制器、鼠标继续、回车继续和教学完成后关闭大厅。
- 保留联机房间准备阶段的节点前置说明：未添加启动器接入码时不会误创建房间，连接节点后再执行实际创建。

此版本为开发测试版，使用 beta 更新通道。Windows 包暂未进行受信任的代码签名；安装前请保留现有启动器和游戏目录备份。
