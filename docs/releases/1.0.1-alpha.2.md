# Buggcraft 1.0.1-alpha.2

发行说明草稿，尚未发布。等待域名接入修改合并和组合回归完成。

本次更新基于 1.0.1-alpha.1，保留原有的首次引导、房间准备、整合包导入导出、下载进度和调试日志功能。

- 修复网络延迟较高时，已经成功的 P2P 直连可能被误判断开、频繁转为中转的问题。
- 改善联机协调通道短暂断开后的恢复，已有的健康直连继续传输；真正断线时仍会切换中转并尝试恢复直连。
- 修复切换联机节点后，个人账号身份可能丢失，导致好友认证失败的问题。
- 个人启动器接入码缺失、失效或验证失败时，提供明确提示和“更换接入码”入口；普通网络故障单独提示。
- 修正大厅“节点延迟”的测量，避免把登录和房间列表加载时间算作网络延迟，并明确说明它与实际游戏延迟的区别。
- 房间目录暂时不可用时，显示刷新或切换节点的中文提示。
- 重新整理整合包导出窗口，显示导出进度并支持取消；完成后由玩家关闭窗口。
- 重复导入整合包时可修改实例名称或取消，保护已有实例；检查和打包过程在后台执行，窗口继续响应。
- 修复并发下载同一文件时的冲突，复用已经安装并校验的 Java；首次从房间安装时自动创建游戏目录。
- 房间成员列表补齐房主标识，房主也可提交诊断；查看玩家安装日志仍需对方授权。
- 补充 UI、下载、导入导出、房间和 P2P 持续回归；实测四个游戏客户端的准备、同步、重生、转让和重入。

这是开发测试版，可在启动器设置中选择“开发版”接收更新。
