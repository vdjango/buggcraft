# Buggcraft 1.0.0-beta.13

- 修复大厅好友入口在社交状态短暂失败后消失的问题。
- 加入房间时可选择复用已有配置增量补模组，或下载独立的新配置；安装完成后立即刷新模组数量。
- 房主可控制是否允许访客从房主端接收模组。直连时优先经 P2P 传输，失败后回退中继，并校验文件哈希。
- 修复房间连接路径变化后界面仍显示“协商中/中转”的状态不同步。
- 下载站同步客户端对临时 HTTP 错误安全重试，并在 401/403 后刷新工作流身份令牌。

本版本已通过 Windows 本机打包自检、房间模组安装与 P2P 双进程集成测试。跨公网双设备、真实 Minecraft 账号登录和各目标平台安装验收仍需完成后再公开发布。
