# Buggcraft 1.0.0-beta.14

- 模组与整合包下载默认 32 路并发，可在设置中调整为 16–64 路；资源节点测速后优先选择较快来源。
- 加入房间支持全新安装与已有配置增量补齐，校验模组文件后立即刷新数量和安装状态。
- 房主可在房间设置中授权模组文件直连传输并限制总上传速度。P2P 作为公共下载源的补充，独立协商文件通道；公共源不可用时可获取房主的私有模组，文件不会经过中转。
- 修复文件通道协商较慢时过早结束下载、迟到协商应答干扰重试，以及联机节点暂时不可用时好友入口和联系人消失的问题。
- 修复发布产物自动同步的连接重试和错误状态；下载站自动获取完整产物后校验并入库，再提供七牛下载与自动更新。
- 自动更新在实际下载时获取七牛签名链接，并校验大小和 SHA-256。

验证：启动器完整预检 351 项通过（1 项跳过）；本机 4 个真实 Minecraft 1.21.8 客户端完成联机和游戏操作；16、32、64 路下载压力测试均完成文件校验。跨公网 NAT 的速度取决于玩家网络，P2P 不保证总能建立。

下载：Windows x64 使用 `Buggcraft.exe`；Linux 按架构选择可执行文件；macOS 按 Intel 或 Apple Silicon 选择压缩包。Windows 暂无受信任的代码签名，macOS 使用 ad-hoc 签名。
