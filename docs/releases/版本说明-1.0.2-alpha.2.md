# Buggcraft 1.0.2-alpha.2

- 房间文件共享加速支持雨云安全直传：一次提交文件清单，由源站批量返回需要补传的文件和短期上传凭证，最多四个文件并行。云端校验文件大小和 SHA-256 后才提供下载，上传失败可回退原有通道。
- 优先复用已匹配的公开来源及源站副本，仅补传缺失或持续过慢的文件。加速任务在后台运行，显示进度和已确认缓存数量，不阻塞普通房间下载。
- 修复早期 NeoForge 格式被识别为 Forge，以及安装后可能误选同名 Forge 配置的问题；房间继续校验实际加载器，错配时给出可操作提示。
- 改善房间缓存进度布局，简化状态展示，并修复下载列表更新时滚动位置跳回的问题。
- 下载策略按已选来源执行，并在需要时使用自建源补齐；整合包、房间文件及已校验资源复用缓存和失败补齐流程。
- 修复安装处理器找不到 Java 时的错误提示，改善 Java 运行时选择与下载过程。

此版本为开发测试版，使用 beta 更新通道。云端直传需节点与源站启用房间文件共享加速；旧服务仍可使用原有上传流程。
