# CurseForge 资源服务

启动器默认查询 `https://download.bugg.icu/api/curseforge/v1`。Modrinth 仍由启动器直接访问；Minecraft 本体、资源与库的下载使用原有 Mojang / BMCLAPI 流程。

## 请求与授权

服务使用 [CurseForge 官方 API](https://docs.curseforge.com/rest-api/)，只开放 Minecraft 的模组、资源包、光影和整合包查询：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/mods/search` | 搜索，固定 `gameId=432`，限定内容类别 |
| GET | `/mods/{project}` | 项目信息 |
| GET | `/mods/{project}/description` | 项目介绍，查询前核验 Minecraft 项目及分类 |
| GET | `/mods/{project}/files` | 文件列表，可分页；客户端默认不加版本条件 |
| GET | `/mods/{project}/files/{file}` | 精确文件信息 |
| POST | `/mods` | 批量项目查询，最多 50 个编号 |
| POST | `/mods/files` | 批量文件查询，最多 50 个编号 |
| POST | `/fingerprints/432` | Minecraft 文件指纹查询，最多 100 个无符号 32 位指纹；精简导出识别公开模组 |
| GET | `/download/{project}/{file}` | CDN 要求鉴权时的备用文件下载 |

接口不接收上游地址，不提供用户、上传或写入操作。搜索结果保留来源；项目编号与文件编号不跨平台混用。服务器只向官方 API 和核验过的 HTTPS `*.forgecdn.net` 文件地址发送 `x-api-key`。元数据请求不跟随重定向；文件下载仅允许官方 CDN 内的 HTTPS 重定向，并限制跳转次数。

默认文件下载不携带公共密钥。CDN 返回 401 后，启动器使用备用接口，服务器核对作者分发许可及文件归属，再流式传输。客户端仍检查文件大小和 SHA-1。作者关闭分发时不会绕过限制。[CurseForge 的 CDN 鉴权说明](https://blog.curseforge.com/introducing-api-key-authentication-for-curseforge-file-downloads/)介绍了文件请求的密钥要求。

## 服务部署

实现位于 `packaging/content_gateway.py`，与联机节点独立部署。准备 Python 3.11 以上环境，将该文件及 `packaging/content-gateway-requirements.txt` 放入 `/opt/buggcraft-content/`，在该目录创建 `venv` 并安装依赖。

将密钥写入 `/etc/buggcraft-content.env` 的 `CURSEFORGE_API_KEY`，文件权限设为 root 所有、`0600`；不要将真实值提交到 Git。复制 `packaging/content-gateway.service` 到 `/etc/systemd/system/buggcraft-content.service`，再执行 `systemctl daemon-reload` 和 `systemctl enable --now buggcraft-content`。更新程序后用 `systemctl restart buggcraft-content`。项目长介绍需要服务端更新后才可用；旧版服务不支持该接口时，启动器仍展示项目摘要、其他元数据及文件列表，并提供项目原站链接。

服务仅监听 `127.0.0.1:18447`，由现有 HTTPS 网站代理：

```nginx
location ^~ /api/curseforge/ {
    proxy_pass http://127.0.0.1:18447/;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header x-api-key "";
    proxy_set_header Authorization "";
    client_max_body_size 32k;
    proxy_read_timeout 30s;
    add_header X-Content-Type-Options nosniff always;
}
```

不开放该本地端口；`X-Real-IP` 必须由受信任的代理覆盖。每个来源地址每分钟最多 120 次请求，最多 8 个并行元数据请求，缓存最多 32 项、有效期 5 分钟。备用文件下载最多并行 2 个、单文件 512 MiB。前置 CDN 未配置可信真实 IP 时，限流会按代理出口计数。部署者还应按实际带宽调整入口限流和服务容量。

服务不记录密钥、请求头或响应正文。Nginx 访问日志沿用网站配置，可能记录查询参数；不要在 URL 中传递密钥。

## 验证

安装上述服务依赖后运行：

```console
python -m unittest tests.test_content_gateway tests.test_curseforge tests.test_content_download tests.test_content_dialog tests.test_modpack_import tests.test_download_transport -v
```

用例覆盖实际 HTTP 路由、分块上游响应、缓存与限流、CDN 鉴权及文件传输、401 自动切换、密钥发送范围、作者限制、版本筛选、校验失败清理和整合包事务导入。外部平台调用使用固定响应；公网下载结果另记于[使用指南](../guides/整合包导入与兼容.md)。
