# 启动器功能覆盖核对清单（按操作顺序）

用于对照现有测试用例，核对启动器功能是否有遗漏。按照“页面 → 功能 → 操作顺序”整理，不展开前置条件、测试数据和预期结果。

本轮报告问题的用例映射及自动回归入口见 [持续回归清单](reported-issues-regression-20261029.md)。新增用例纳入 `tests/` 和 CI，不以一次性脚本代替后续回归。

`→` 表示操作顺序；`｜` 表示同一功能需要分别覆盖的分支。只使用 `[x]` 完成、`[ ]` 未完成：该条全部分支已执行并有通过证据才打勾，存在未验证分支就不打勾。测试方法与执行证据见 [客户端 UI 测试矩阵](client-ui-test-matrix.md)。

## 1. 启动器首页

逐条步骤、预期及证据对应 [首页测试用例 HOME-01 至 HOME-48](launcher-home-test-cases.md)。真实离线游戏及四客户端结果见 [GAME-01 至 GAME-06](launcher-game-launch-test-cases.md)。本轮按要求不测试正版登录；缺少真实环境证据的分支不打勾。

### 1.1 启动与初始页面

- [x] 打开启动器 → 首次教学（首次使用时）→ 完成教学 → 返回首页 → 重启，完成标记仍有效且延迟教学不重现（HOME-45）。
- [x] 资源缺失或 Qt 初始化失败 → 显示恢复说明、完整安装包建议与日志位置（HOME-48）。
- [x] 打开启动器 → 恢复上次角色、游戏目录和所选实例 → 展示首页。
- [x] 无账号、无已安装游戏时 → 查看首页空状态 → 进入登录/下载入口。

### 1.2 头部版本切换

这里的“版本”指已安装的游戏版本；启动器自身更新在设置页。

- [x] 首页 → 头部“版本” → 展开版本列表 → 选择版本 → 首页启动目标同步。
- [x] 版本列表 → 切换另一个版本 → 再切回原版本。
- [x] 版本列表 → 键盘上下选择/回车确认｜Esc 关闭｜点击外部关闭。
- [x] 无已安装版本 → 打开版本列表 → 空状态；完成安装后 → 返回列表查看新版本。

### 1.3 离线登录（你列的“盗版登录”）

- [x] 首页 → 左侧“离线登录” → 输入用户名 → 确认｜回车 → 展示角色。
- [x] 离线登录 → 空用户名｜纯空格 → 提交 → 查看提示。
- [x] 已登录 → 切换账号 → 输入另一个用户名 → 确认。
- [x] 离线登录 → 切换正版登录 → 再切回离线登录。

### 1.4 正版登录

- [ ] 首页 → 左侧“正版登录” → 点击登录 → 获取/复制设备登录码 → 浏览器完成微软授权 → 返回首页展示角色。
- [ ] 正版登录 → 取消/关闭登录窗口 → 再次登录。
- [ ] 正版登录 → 授权拒绝｜登录码过期｜网络异常｜无有效 Java 版角色 → 提示 → 重新登录。
- [ ] 已登录 → 切换账号 → 使用另一账号登录。
- [ ] 重启后恢复正版账号 → 令牌刷新成功后启动｜刷新失效后重新授权。

### 1.5 游戏启动与停止

- [x] 离线登录 → 选择已安装版本 → 启动真实 Minecraft → 进入游戏主菜单 → 正常退出并再次启动 → 首页恢复（GAME-01）。
- [ ] 正版登录 → 选择已安装版本 → 启动游戏；本轮按要求不测试微软授权登录。
- [x] 未登录｜未选版本 → 点击启动 → 查看提示 → 补齐后再次启动。
- [x] 启动游戏 → Java 参数启动失败 → 查看实际 JVM 输出/日志 → 修复后重试（GAME-08）。
- [x] 启动游戏 → Java 缺失/不兼容、版本 JSON 缺失/损坏、启动参数无法解析 → 查看提示/日志 → 修复后重试（HOME-47）；使用实际启动线程和子进程，真实 JVM 参数失败另见 GAME-08。
- [x] 游戏运行中 → 停止游戏 → 进程退出 → 首页恢复（GAME-06，真实 Java/Minecraft 进程）。
- [x] 游戏运行中 → 真实 Minecraft 异常退出 → 查看状态/日志 → 重新启动。
- [x] 关闭“允许多开游戏” → 启动游戏 → 再次点击变为停止并回收实际进程（GAME-06）。
- [x] 开启“允许多开游戏” → 启动 4 个真实客户端 → 选择会话 → 停止当前游戏 → 其他会话继续运行（GAME-06）。

### 1.6 左侧菜单与页面切换

- [x] 首页 → 收起左侧菜单 → 打开左侧菜单 → 再操作登录入口。
- [x] 首页 → 下载 → 设置 → 开始 → 查看当前页面和导航选中状态。
- [x] 下载页｜设置页 → 收起菜单 → 打开菜单 → 切换页面。
- [x] 页面内输入/选择内容 → 切到其他页面 → 返回原页面；连续快速切换页面。
- [x] 最小化 → 任务栏恢复；拖动标题栏；关闭 → 重新打开（Windows 原生窗口实测）。

### 1.7 实例切换与管理

- [x] 头部“实例” → 选择游戏目录 → 查看实例列表 → 选择实例 → 返回首页 → 启动目标同步。
- [x] 实例 → 添加游戏文件夹 → 选择目录 → 查看其中的实例 → 切换到另一个目录。
- [x] 实例 → 安装新游戏 → 进入下载页 → 安装完成 → 返回实例列表。
- [x] 实例 → 对应实例“设置” → 修改独立设置 → 返回 → 切换其他实例。
- [x] 实例 → 对应实例“目录” → 打开本地文件夹（Explorer 实际窗口核对路径）。
- [x] 实例 → 删除 → 取消｜确认 → 列表和当前版本更新；运行中实例的删除提示。
- [x] 游戏目录 → 移除目录 → 查看确认 → 取消｜确认；当前实现的确认操作会删除整个目录及文件，并非只隐藏列表项。
- [x] 切换空目录｜删除当前实例｜删除最后一个实例 → 返回首页 → 查看版本与启动状态。

### 1.8 进入联机大厅

- [x] 首页 → 联机大厅 → 展开节点列表 → 选择节点 → 查看房间列表。
- [ ] 无节点/接入码 → 查看空状态及可用入口；添加有效接入码后 → 再进入大厅。
- [x] 大厅 → 搜索房间 → 进入创建/加入入口 → 返回大厅。
- [x] 关闭大厅 → 返回首页 → 再次进入大厅。

### 1.9 进入好友页面

- [x] 首页 → 好友 → 好友列表 → 搜索 → 在线筛选 → 清空筛选。
- [x] 好友页面 → 好友申请 → 联机邀请 → 加入申请 → 返回好友列表。
- [x] 有未读消息 → 从首页进入对应页签 → 查看/处理 → 返回首页查看未读提示。
- [x] 关闭好友窗口 → 返回首页 → 再次进入；无好友/无节点时查看空状态和提示。

大厅和好友的完整业务操作另见 [联机回归用例](multiplayer-regression-cases.md)，这里核对首页入口、页面切换和返回链路。
