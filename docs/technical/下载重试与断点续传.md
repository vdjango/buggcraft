# 下载失败、重试与断点续传

适用入口：游戏下载、资源下载、整合包导入、在线整合包安装、房间客户端同步。

## 使用行为

- 网络中断时自动重试并尝试可用的备用源；全部失败后，用户可从下载记录继续安装。
- 整合包重试沿用原任务，复用已校验的文件，保留未完成文件的下载进度。
- 房间页失败后显示“重试下载”；下载记录里的房间任务也可以重试。已离开的房间会提示重新加入。
- 房间下载缓存独立于临时安装目录；失败清理临时实例时，不删除已下载的文件及可续传的数据。
- 下载源优先；仅在已经建立 P2P 直连时允许从房主下载。中转连接不启用此备用下载。
- 下载返回网页、错误响应或损坏的数据时，不发布无效的版本信息、资源索引或整合包实例。界面说明失败的信息项及重试方式，详细错误记入日志。
- 整合包自身的清单损坏时，提示重新导出或重新下载，避免把 JSON 解析器异常直接交给玩家。

## 数据与兼容

公共下载使用 `<文件名>.buggcraft-part` 和同名 `.json` 检查点，记录预期哈希和总长度。检查点不匹配时丢弃旧分片；成功后先校验再原子替换目标文件，并删除检查点。

服务器支持 HTTP Range 时继续剩余字节；服务器忽略 Range 时重新下载该文件。哈希或长度校验失败的数据不会用于续传。取消并发分段下载时只保留连续的前缀，避免拼接不连续的数据。

房间文件缓存位于 `.buggcraft-downloads/room-content/<SHA-256>/content`。复用前重新校验长度和 SHA-256。原生 P2P 暂无字节范围协议，仅复用完整并通过校验的文件；公共源的断点续传独立保留。

## 回归用例

以下测试操作实际下载器、导出器和安装器。HTTP 服务器在本机提供可控响应，模拟断线、错误内容和恢复；UI 用例通过 Qt 鼠标、键盘事件操作生产界面。

- [x] `test_download_transport.py`：自动重试耗尽后新建下载器仍可续传；无清单长度时记录响应长度；身份变化不拼接旧数据；取消并发分段下载后续传；损坏信息切换来源且不缓存错误响应。
- [x] `test_room_mod_installation.py`：清理失败的临时实例后复用已完成模组；公共下载中断后按 Range 继续；中转连接禁止 P2P 下载；下载并发限制不变。
- [x] `test_modpack_import.py`：损坏的自有格式清单显示明确提示，保留原有导出、导入和文件完整性验证。
- [x] `test_loader_catalogue.py`：加载器 JSON 响应异常显示可操作的提示并释放响应。
- [x] `test_room_preparation_controller.py::RoomPreparationControllerTests::test_room_history_retry_reuses_task_and_refuses_a_disconnected_room`：房间重试沿用原任务，已断开的房间拒绝重试。
- [x] `test_download_ui.py::DownloadChecklistUiTests::test_own_export_import_metadata_error_is_readable_and_ui_retry_completes`：真实导出 `.buggpack`，界面导入遇到异常版本信息，点击重试并核对安装结果。
- [x] `test_download_ui.py::DownloadChecklistUiTests::test_own_export_import_interrupted_resource_resumes_from_ui`：自有整合包资源下载断线，点击重试，核对 Range 偏移及模组、资源包、光影的最终字节。
- [x] `test_download_ui.py::DownloadChecklistUiTests::test_room_failed_download_history_button_reuses_task_and_file_rows`：点击下载记录中的房间重试按钮，沿用任务并刷新文件状态。
- [x] `test_room_lobby_ui.py::RoomLobbyUiTests::test_guest_failed_download_retries_original_install_mode_from_room_button`：点击房间页重试，使用原安装模式。

运行入口：

```powershell
python -m pytest -q tests/test_download_transport.py tests/test_room_mod_installation.py tests/test_modpack_import.py tests/test_loader_catalogue.py tests/test_download_concurrency.py tests/test_room_preparation_controller.py
python -m pytest -q tests/test_download_ui.py tests/test_room_lobby_ui.py tests/test_loader_source_ui.py
```

默认使用隔离的 Qt 环境；设置 `QT_QPA_PLATFORM=windows` 可在 Windows 桌面查看自动操作，`BUGGCRAFT_UI_OUTPUT` 指定操作记录及截图的保存位置。测试资源不是真实 Minecraft，不能据此宣称已完成真实游戏启动或多人游戏验收。
