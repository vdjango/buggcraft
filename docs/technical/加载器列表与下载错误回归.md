# 加载器列表与下载错误回归

工作分支为 `main`。本轮处理页面直接出现 JSON、连接池和请求异常，以及加载器列表加载失败的问题。保留其他窗口的修改，不涉及发布版本。

## 修复范围

- [x] NeoForge 镜像列表改用 BMCLAPI `/neoforge/list/<游戏版本>`，按实际 JSON 格式解析；官方仍读取 Maven 元数据。
- [x] 自动模式按设置顺序访问来源，来源返回空结果、不匹配数据或损坏信息时继续尝试下一个来源。明确选择官方或 BMCLAPI 时不擅自更改来源。
- [x] Forge、NeoForge、Fabric、Quilt 列表只呈现兼容版本；去重及排序，保留 Fabric 旧式 `+build` 构建和 NeoForge 省略补丁号的游戏版本。
- [x] 加载器列表错误显示简短说明及恢复操作，网络原始错误留在日志。
- [x] 下载任务、历史记录、文字日志及文件进度的错误展示不直接输出 JSON、URL 或连接池异常；保留可识别的本地失败文件名与时间。原始诊断保存在任务记录和程序日志。
- [x] 内容列表和整合包检查的异步任务使用同一错误转换；房间安装的状态和页面错误同样处理，历史日志保留原始原因。
- [x] 新增可重复运行的单元及 Qt UI 用例，并加入 `package.yml`、`client-regression.yml`。

## 自动化用例

| 测试入口 | 验证内容 |
|---|---|
| `tests/test_loader_catalogue_regressions.py` | NeoForge 专用接口、官方回退、来源限制、游戏匹配、空响应及异常响应、数值排序、旧 Fabric 构建、响应释放和完整错误日志 |
| `tests/test_download_error_presentation.py` | 包装后的超时异常、JSON 错误体、JSON 解析异常、网络错误转换；保留已有可读说明和正常状态 |
| `tests/test_catalogue_source_regression_ui.py` | 真实点击设置中的三个来源，依次读取并选择四种加载器版本；HTTP 失败、错误 JSON、点击重新加载恢复；历史任务卡片与文字日志 |
| `tests/test_task_history_qml.py` | 任务卡片和文件错误转换不修改保存的诊断内容 |
| `tests/test_room_preparation_controller.py` | 房间安装失败的页面、状态与历史日志分别核对 |

UI 使用生产窗口、控制器、后台工作线程及真实本机 HTTP 服务。仅将远程请求重定向至可控 HTTP 响应，保留生产接口选择、解析和页面事件处理。此组不代表真实游戏启动或多人游戏验收。

```powershell
python -m pytest -q tests/test_loader_catalogue_regressions.py tests/test_download_error_presentation.py tests/test_task_history_qml.py tests/test_room_preparation_controller.py
python -m pytest -q tests/test_catalogue_source_regression_ui.py tests/test_loader_source_ui.py tests/test_download_ui.py
```

使用 `QT_QPA_PLATFORM=windows` 可查看桌面上的实际自动操作，`BUGGCRAFT_UI_OUTPUT` 指定截图和操作记录目录。

## 真实网络查询

使用生产 `available_versions()`，查询 Minecraft `1.21.8`，来源为“自动（镜像优先，失败切换官方）”。四种列表均已成功返回；Quilt 镜像返回 404 后通过官方取得列表。原始验证记录保存在工作区 `.test-tools/loader-catalogue-20261029/live-catalogue.json`。远端版本数量会变化，此结果只说明该次查询成功。

接口参考：[BMCLAPI](https://bmclapidoc.bangbang93.com/)、[Fabric Meta](https://github.com/FabricMC/fabric-meta/blob/master/README.md)、[Quilt Meta](https://meta.quiltmc.org/index.html)。
