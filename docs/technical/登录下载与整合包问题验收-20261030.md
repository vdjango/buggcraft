## 下载源规则

模组与整合包提供自动测速、CurseForge、Modrinth、MCIM 四种选项。切换发布平台时必须找到长度和哈希一致的文件；所选平台没有同一文件时保留原平台地址，不能仅按名称替换为另一个模组。

游戏与加载器默认 BMCLAPI，增加 [MCMirror](https://mirror.minguncle.cn/) 作为可选择来源与回退来源。该站点公开的服务范围是游戏本体、资源、库与加载器，不用于替换 Modrinth/CurseForge 模组地址。镜像返回的改写地址可还原发布者地址，再按当前设置重新路由。手动来源选择表示优先来源，遇到失败仍尝试其余适用来源。

MCIM 按以下四条映射处理，保留路径、查询参数及编码：

| 原域名 | 镜像入口 |
|---|---|
| `api.modrinth.com` | `mod.mcimirror.top/modrinth` |
| `cdn.modrinth.com` | `mod.mcimirror.top` |
| `api.curseforge.com` | `mod.mcimirror.top/curseforge` |
| `edge.forgecdn.net` | `mod.mcimirror.top` |

`mediafilez.forgecdn.net` 保留原址，不直接替换。MCIM 返回的缓存日期用于核对时效；过期、缺失或错误响应不能直接当作最新上游数据。文件请求重定向后，下载列表显示实际响应的来源。

精简导出只在确认可公开下载时省略本地模组。未发布、查询失败或链接不可用时随包保存，因此全部模组都需要内置的整合包，两种导出的大小仍可能接近。
