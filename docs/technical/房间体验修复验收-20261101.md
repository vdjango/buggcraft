# 房间体验修复与回归（2026-11-01）

本次覆盖房间布局、成员身份/游戏状态、邀请状态、剪贴板生命周期、内存提示、自有整合包下载策略及预留下载源。保留原有 CurseForge / Modrinth / 混合导出选择，不修改发布版本号。

## 功能与用例

| 项目 | 行为 | 自动化入口 |
| --- | --- | --- |
| 房间布局 | 信息默认收起；聊天优先，成员/日志独立滚动；折叠不隐藏启动、进度、速度、取消和重试 | `test_room_lobby_ui.py`、`test_lobby_layout.py` |
| 成员身份 | 按稳定成员 ID 更新；角色名绑定实际游戏实例和启动账号，节点账号另列，不因登录切换串名 | `test_game_sessions.py`、`test_room_preparation_controller.py`、节点 `test_member_identity.py` |
| 游戏状态 | 根据匹配实例的实际进程上报 starting/playing/ready，包含配置指纹及定期心跳 | `test_room_preparation_controller.py` |
| 邀请 | 已接受、五分钟超时、房间结束后清理发出邀请；邀请不覆盖好友在线状态 | `test_friend_entry_regression.py` |
| 剪贴板 | 创建/加入流程、连接中和房间存在期间暂停；退出后恢复，读取失败不阻塞 Qt | `test_launcher_qml.py`；既有剪贴板事件回调回归 |
| 内存 | 启动前简短 GB 建议；持续系统内存压力提示一次，恢复后可再次提醒；返回调整打开设置 | `test_launch_preflight.py`、`test_game_sessions.py`、`test_memory_warning_ui.py` |
| 自有整合包 | 默认原地址，失败才解析设置源；可选择设置源；第三方包不暴露此策略；哈希不降级 | `test_pack_download_fallback.py`、`test_modpack_import.py`、`test_download_ui.py` |
| 预留镜像 | `mirror.bugg.icu` 与翻译平台路由对齐，`ENABLED=False`；关闭时不进入候选地址或发请求 | `test_bugg_mirror.py` |
| 诊断上传 | 房主/房客入口保留；页面展示简短错误，详细拒绝原因写日志 | `test_room_lobby_ui.py`；原生 `test_feedback_native.py` |
| 首次教学 | 设置展开/滚动后及时重新定位高亮，教学完成退出大厅，非教学区域仍锁定 | `test_onboarding.py` |

真实节点 UI 用例 `test_room_lobby_live_ui.py` 启动 C++ 核心、两条桥会话并操作发布 QML，验证聊天、请求/允许/撤回日志以及双方确认转让管理权。外壳和账号使用隔离夹具，不把这项称为公网四游戏验收。

下载兜底用例使用真实本地 HTTP 验证原地址成功不查询备用源、原地址失败只尝试未使用的备用地址、错误文件被哈希拒绝及完整文件复用。内存压力为可重复注入的系统指标，不以真的耗尽用户电脑内存验收。
