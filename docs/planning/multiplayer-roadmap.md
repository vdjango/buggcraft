## 本轮实施顺序

1. 保留原有加密数据面，扩展有大小限制的房间信息/开放目录控制协议。
2. 恢复本机 Minecraft LAN 发现，默认不对其他局域网设备开放本地代理端口。
3. 重做联机大厅：固定导航、开放房间列表、独立好友页、创建/加入向导、节点管理、版本提示。
4. 修复审查中确认的问题，补充自动化测试、并发测量和真实游戏回归。
5. 更新本表、部署步骤和测试报告；未实测的平台/容量继续保留为未验收。

## 好友与账号边界

匿名使用不要求注册，但没有好友列表、好友搜索或在线状态。房间邀请码是一种持有即获准加入的凭据，不展示在公共房间列表或日志中。开放房间的加入凭据只向持有该节点服务配置的使用者发放。

2026-10-21：好友可在启动器中选择任一同联邦节点作为网络入口，按用户名或完整账号 ID 精确查找、双向同意好友请求、查看在线状态并邀请加入；公开用户名目录在已连接联邦节点间同步，不需要同意备份。用户名重复时使用完整账号 ID。目录不包含密码、登录令牌、私密资料或 IP；账号登录仍由注册节点或已同意的备份节点处理。好友关系不是房间权限，加入仍须有效邀请。详见 [账号安全与复制边界](../technical/node-accounts-security.md)。
