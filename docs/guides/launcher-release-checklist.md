# 启动器发布验收清单

每次候选版本发布前都要运行自动测试，并在目标系统完成真实安装验收。自动化用例不能替代正版账号、真实 Minecraft 世界和公网网络验证。

## 固定发布流程

所有后续修复先在独立的 `release/*` 分支和工作树完成。推送该分支会运行完整的 `Package launcher` 五平台构建；分支全绿后才合入 `main`，再等待 `main` 的最终提交五平台全绿并按下面流程发布。其他并行任务使用各自工作树；若 `main` 在验证后更新，必须验证更新后的提交。

1. 将完整修复推送到 `main`，等待 `Package launcher` 的 Windows x64、Linux x64 / ARM64、macOS Intel / ARM64 五个平台全绿。
2. 在 GitHub Actions 运行 `Release launcher build`，分支选 `main`，手动填写已经确定的完整版本号。工作流会拒绝没有同一提交全绿构建、缺少发行说明或已有 GitHub Release 的请求；不会计算或递增版本号。
3. 工作流将指定标签指向已验证提交，并显式派发 `Package launcher`。标签构建再次检查同一 SHA 的 `main` 成功记录，然后生成五个平台的启动器包、校验文件与 GitHub 草稿。
4. 等待下载站缓存同步成功，检查五个平台的文件、版本标记、大小和 SHA-256，再将该版本从待审核发布。
5. 如果任何检查失败，修复后回到第 1 步。若标签已经生成但打包失败，重跑该标签的失败任务；不更改版本号。若 GitHub 草稿已存在，只重跑失败的同步任务，不重打标签。

单独的 C++ 联机桥工作流不是启动器发布结果；启动器发布以 `Package launcher` 全平台成功和下载站资产校验为准。

## 安装与启动

- [ ] 在干净目录首次启动，确认窗口、图标、中文字体和 QML 页面正常。
- [ ] 使用正版 Microsoft 账号登录、退出并重新登录；确认账号切换和错误提示正常。
- [ ] 离线账号启动已有实例；退出后再启动在线账号实例，确认身份不会串用。
- [ ] 安装一个当前稳定版 Minecraft，等待资源下载、校验和安装完成后启动到主菜单。
- [ ] 分别启动一个 Forge/Fabric/Quilt/NeoForge 实例；若候选版本不支持某加载器，在发布记录里注明。
- [ ] 启动一个真实存档，打开局域网，确认启动器状态与游戏状态一致；正常退出并检查大厅恢复。
- [ ] 启动参数异常、Java 缺失、网络中断或用户取消时，确认游戏不会错误启动且错误信息可读。

## 设置与实例

- [ ] 保存并重启后检查启动器透明度、关闭行为、内存、窗口尺寸和游戏目录设置。
- [ ] 切换全局设置与单实例设置，确认作用范围正确。
- [ ] 手动选择 Java 8、17、21 或 25 中适用于候选游戏的版本；验证旧版 Forge 与新版 Minecraft 的 Java 要求。
- [ ] 添加、切换、导入和删除游戏目录；确认正在运行或被房间使用的实例受到保护。
- [ ] 用已有 `.mrpack` 或 CurseForge 整合包导入一个副本，确认加载器、模组和配置文件完整。
- [ ] 安装并移除一个模组、资源包和光影；验证只影响当前选择的实例。
- [ ] 暂停、取消、重试一个大文件任务，确认部分文件不会冒充完整文件，任务记录可读。

## 联机

- [ ] 添加并验证可信节点，切换节点、刷新大厅和断开网络后重连。
- [ ] 两台不同网络的客户端使用同一节点，一个创建公开房间，另一个搜索并加入。
- [ ] 使用邀请加入私密房间；测试错误邀请、过期邀请和重复加入提示。
- [ ] 按默认 P2P 优先连接一局，再选择仅中继连接一局；在游戏里互相移动并验证聊天/数据传输。
- [ ] 测试游戏版本、加载器或模组不匹配时的阻止/提示行为。
- [ ] 主机和访客分别正常退出游戏与房间；断网后确认状态不会假报已连接，并可恢复。
- [ ] 运行时导出诊断信息，检查日志没有密码、账号令牌或完整接入码。

## 更新与各平台

- [ ] 在 Windows x64 干净环境安装本次候选包，验证签名状态和 SmartScreen 告警说明。
- [ ] 将后台测试通道发布一个更高测试版本，客户端确认提示、下载、SHA-256 校验、替换和重启。
- [ ] 发布一个更高稳定版本，验证稳定通道更新；撤回版本后确认不再被推荐。
- [ ] 在 macOS Intel 与 Apple Silicon 分别安装并更新；验证 Gatekeeper 提示、应用替换和旧版回滚。
- [ ] 在 Linux x86_64 干净环境运行并更新；验证执行权限、桌面环境和重启。
- [ ] 每个平台检查官网系统识别、正确安装包、历史版本、校验文件和发行说明。

未完成人工项时，不要把候选版本设为公开发布。Windows/macOS 当前无受信任签名时，应先配置签名与公证流程，再面向普通玩家发布。
