# 游戏日志窗口

在「设置 → 全局设置 → 游戏调试模式」选择「是」，或在实例独立设置中启用调试。启动游戏后自动显示日志窗口；游戏退出后保留最近的输出，关闭窗口不会终止游戏。异常启动后的「查看日志」也打开同一个窗口。

- 搜索支持大小写不敏感的文本，也可打开「正则」。表达式错误会在工具栏下显示，不丢弃收到的日志。
- 按级别筛选全部、警告与错误、错误、普通信息、调试信息。
- 按模组、加载器、Java、网络、渲染、游戏或启动器分类，再按来源名称筛选单个模组或 logger。分类来自日志标签和内容，是排查提示，不保证所有第三方模组都提供可识别标签。
- 时间、异常类、网址、字符串、资源命名空间和数字分别着色；错误行另有底色。富文本先转义，日志中的 HTML 不会执行或加载远程内容。
- Java 堆栈后续行继承上一条错误的级别与来源，筛选错误时不会丢失调用栈。
- 「暂停显示」只冻结列表，后台继续接收；「继续接收」显示暂停期间的输出。「自动滚动」可以关闭。
- 「复制筛选结果」「导出筛选结果」只包含当前筛选后的纯文本。最多保留最近 5000 行；游戏目录中的完整 logs/latest.log 不受影响。

自动化入口：python -m pytest tests/test_game_log_ui.py。用例使用真实 Qt 鼠标、键盘、下拉框与文件输出；真实游戏的自动弹窗和实际输出由 tests/test_game_launch_live.py 验证。
